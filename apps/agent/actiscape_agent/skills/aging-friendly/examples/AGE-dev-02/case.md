# AGE-dev-02 · 床侧只剩 450（边界／失败）

## 输入

同一个 3900 × 5000 主卧：南墙房门 900、东墙窗 1600；空场景。`min_passage` 800。

## 用户／错误做法

"床横过来靠西墙，西侧留 450 侧身就够了；这样床尾还能放个斗柜。"
结果：1800 床横放后，西侧只剩 450（低于 800），且床体一直顶到南墙，把门洞的 300 落脚带整个压住。

## 技能应如何反应

拒绝这个方案，并给出替代：

1. 450 是"侧身通过"，不是适老净宽；本技能取 800，`J-CIR-04` 的 600 也不够；
2. 床不能压住门的 300 落脚带，也不能进 900 门扇扫掠；
3. 面积不够时先减家具（斗柜、单人椅），不要减净宽——这是本技能第 1 步的取舍顺序。

## 判定

`check.run` 应报 `CIR-02`（门口落脚带被床占满，门到房间主区不通）。
同一位置也落在门扇扫掠内，会同时报 `DOOR-02`。450 的侧身缝在引擎里仍算"可通行格"，所以它本身不会触发通道码——真正被拦的是"门被堵死"，这正是适老场景最危险的一种。
