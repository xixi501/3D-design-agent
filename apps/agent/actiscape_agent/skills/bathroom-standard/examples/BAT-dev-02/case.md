# BAT-dev-02 · 马桶挡住门扇（边界／失败）

## 输入

- 同一个 1.8 × 2.4m 卫生间（4.32㎡），南墙 700 内开门。
- 淋浴 900 × 900 仍在西北角，浴室柜仍在东墙南段。

## 用户／错误做法

"马桶放门边顺手，进门就能用。"

马桶 700 深 × 400 宽，中心 (750, 1900)，背面朝南（rot 180），占 x 550–950、y 1550–2250——正好压在门扇 700 × 700 的扫掠区里。

## 为什么必须拦

门内开时，门扇扫掠的那块地面是"被门占用的"，不是可用面积。马桶压进去的后果不是"挤"，而是**门只能开到 45°**：

- 人侧身才进得去，搬浴缸、搬洗衣机时直接进不了门；
- 门扇边缘会撞马桶水箱，长期使用会把门锁与合页撞松。

## 技能应如何反应

拒绝这个位置，按顺序给三条替代：

1. 马桶退回东墙（面朝西），让出整块门扇扫掠区 [J-DOOR-02]；
2. 门改**外开**，把这 700 × 700 收回来给马桶；
3. 门改**折叠/推拉**，但暗卫不建议（密封与隔声差）。

前提仍是排水立管不移位——如果立管真的在门口，应如实报告"这个卫生间放不下内开门 + 马桶"，交主控决定是否改立管 [J-VER-02]。

## 判定

`check.run` 应报 `DOOR-02`（门 d1 开启范围内有马桶）；技能不得把该方案标为已完成。
