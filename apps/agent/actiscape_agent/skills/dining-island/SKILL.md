# 餐厨一体与中岛

> v1 接入说明：本 Skill 只声明语义 capability，不能直接写正式场景、提交项目或执行任意脚本。所有修改必须形成候选，并由固定代码预检、渲染、审核和提交。

## 什么时候用

✅ 适用：

- 餐厨一体、开放式厨房，面积 4–30㎡，已有一版含墙体与门窗的场景；
- 用户要加中岛、要把岛台当早餐台、或"厨房和餐厅怎么摆在一起"；
- 要判断"岛台 + 独立餐桌"能不能同时成立。

❌ 不适用（转其他技能）：

- 封闭式独立厨房、不做岛：转 `kitchen-line-l-u`（选形与操作三角逻辑不同）；
- 岛台只做吧台、不涉及厨房动线（家庭咖啡角/酒水角）：转 `style-coherence` 或 `living-dining-small`；
- 要改燃气、排烟、下水立管：超出本技能，交回主控 [J-VER-01]；
- 岛台要通水（水槽上岛）：先确认排水坡度与立管位置，确认不了就不要把水槽放上岛。

开工前只问三件事（问不到就按保守值）：

1. 岛台是**只做操作**、**操作 + 早餐**、还是**兼餐桌**（三条路的间距完全不同）；
2. 家里的动线是"进门 → 冰箱"还是"进门 → 餐桌"（决定主通道放哪一侧）；
3. 常住几口人（决定吧椅数与岛台长度，而不是反过来先定台面）。

## 怎么做

**第 1 步 · 先定岛台的角色（本技能的第一个判断，别跳过）**

| 角色            | 台面深度 | 外挑                  | 需要额外的东西                    |
| --------------- | -------- | --------------------- | --------------------------------- |
| 纯操作岛        | 600–900  | 无                    | 与橱柜形成双排，通道按 [J-KIT-02] |
| 操作 + 早餐吧台 | 900–1000 | 单侧外挑 250–300 放腿 | 吧椅数 = 台面长 / 600（向下取整） |
| 岛台兼餐桌      | 900–1200 | 两侧外挑              | 不买独立餐桌，人均 600 沿长边排   |

**岛台兼备餐与早餐**是本技能的核心取舍：餐厨一体面积 < 12㎡、或房间净深不足以同时放"岛台 + 餐桌 + 两侧椅子"时，**合并成一张岛台**，而不是把两件家具硬塞。合并后失去的是"正式用餐的仪式感"，换来的是通道与厨房操作面；两件都想要，通常两件都不好用。

**第 2 步 · 定岛台与橱柜/墙的通道** [J-KIT-02] [J-CIR-01]

- 岛台正对橱柜 = 双排，按 [J-KIT-02] 的双排口径；岛台对墙按单排口径；
- **岛台两端必须各留一条能绕行的缝**，不要一头顶墙、一头顶柜——那会把厨房做成死胡同，冰箱门和水槽只能从一侧进 [J-CIR-01]；
- 岛台长度 ≤ 房间短边 − 2 × 通道；算不下就缩岛台，不要缩通道；
- 岛台与橱柜之间是**工作通道**，不是主通道：主通道要放在岛台外侧，否则做饭时永远有人横穿。

**第 3 步 · 定岛台与餐桌的关系（夹缝是最常见的错）** [J-CIR-03] [J-CIR-07]
只有两种关系，没有第三种：

1. **并台**：桌边贴岛台，缝隙落在 [J-CIR-07] 的区间内，台面连成一片，椅子只挂在岛台外侧；
2. **分置**：桌边到岛台边 ≥ [J-CIR-03]，两张独立的家具，中间是通道。

落在两者中间的宽度最糟：既不能当连续台面用（东西会掉），也不能走人（侧身都难）。遇到这个宽度，先做减法——缩桌子、换方向、或把餐桌并进岛台。

还要注意：分置的净距是**桌边到岛台边**的距离；一旦桌上坐人、椅子推进，这条就只剩一条"坐人缝"。所以主通道永远不要安排在这条缝里，要放在桌子的长边外侧 [J-CIR-01]。

**第 4 步 · 吧椅与进出** [J-CIR-01]

- 吧椅座高与台面高要配套，台面外挑要让膝盖进得去；椅面到台面边不要留出一条能掉东西的缝；
- 吧椅背后按 [J-CIR-01] 留；背后是墙时按小空间下限，且**不要让人背对通道**（端热锅时最危险）；
- 吧椅不要放在岛台的转角上（进出要绕），靠长边均匀排；
- 岛台兼餐桌时，吧椅就是餐椅，椅背到墙的距离要按餐椅口径复核，不要按吧椅口径。

**第 5 步 · 吊灯与台面照明** [J-LIGHT-02]

- 岛台吊灯底距台面 750–900：低于 750 碰头挡视线，高于 900 就变成环境光；
- 吊灯总直径 ≤ 岛台长度的 2/3；两盏时按岛台三等分放，不要挤在中间；
- 吊灯只做重点照明，岛台台面的**作业照度按 [J-LIGHT-02] 的厨房台面档**，靠柜底灯或筒灯补；
- 吊灯不要装在灶台正上方（那里是油烟机的位置），也不要装在水槽正上方（低头洗东西会撞头）。

**第 6 步 · 分批提交与检查（不要一次改完再检查）**

1. 先提交橱柜与岛台，`candidate.propose + candidate.preflight` 带 `base_version`、`op_id` 唯一；
2. `candidate.preflight / candidate.review` 看通道、重叠、门洞；
3. 再提交餐桌组、吧椅、吊灯，再检查；
4. 最多 3 轮修复 [J-VER-02]；3 轮后仍不通过的写进"未解决清单"，不要用"看起来宽敞"收尾；
5. 只改本次涉及的家具，户型与无关家具不动 [J-VER-01]。

与原项目 Skill 的差异：原流程靠"看效果图判断岛台够不够宽"，本技能把"角色 → 通道 → 桌岛关系"三步写成可复核的顺序，**先算宽度再谈样式**；岛台尺寸沿用上游目录（1800 × 900）作为起点，不另造一套。

未适配时的降级路径（状态仍为 `pending_adaptation`）：

- 没有 `scene.*`：输出"岛台坐标 + 三条通道宽度 + 桌岛关系"的文字表，交主控转场景；
- 没有 `candidate.preflight / candidate.review`：按第 2、3 步的判据人工核算，交付里注明"未经工具检查"。

## 怎么验证

- **正向** `ISL-dev-01`：4.2 × 4.8m 餐厨一体（20.2㎡）。北墙橱柜 3000、岛台 1800 × 900 对橱柜留 1000、岛台东端挂两把吧椅、餐桌 1400 × 800 与岛台留 900、四把椅子（两端 + 北侧两把）、岛台上方两盏吊灯。期望 `candidate.preflight / candidate.review` 全通过：走廊 ≥ 900、推拉门前 400 净空、无重叠、吸顶件不参与贴墙判定。
- **边界** `ISL-dev-02`：同一尺寸的餐厨，岛台做到 2400 长、一路顶到通客厅的垭口，餐桌与岛台之间只剩 600 的夹缝。期望报 `CIR-02`——垭口被岛台堵死，客厅进不来；技能要拒绝并给出"缩岛台 / 换方向 / 岛台兼餐桌"三条替代。

两个案例都在 `examples/` 下，`ops.json` 可被 mock 引擎复跑；L1 结构与 L2 几何结果记录在 `manifest.validation`。
