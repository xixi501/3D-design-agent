# ISL-dev-01 · 4.2 × 4.8m 餐厨一体（正向）

## 输入

- 场景：矩形餐厨，轴线 4200 × 4800 mm，墙厚 200，内净约 18.4㎡（轴线面积 20.16㎡）。
- 洞口：
  - 东墙平开窗，宽 1400（距北端 2800），窗台高 900、窗头 2400；
  - 南墙推拉门，宽 1550（距西端 2450），通客厅。
- 用户原话："两口人，早上在岛台吃，晚上正经吃饭；厨房要能两个人同时站，别把客厅入口堵了。"

## 技能给出的方案

- **角色**：操作 + 早餐（岛台东端外挑挂两把吧椅），**另设**独立餐桌——因为净深 4600 恰好放得下"橱柜 600 + 通道 1000 + 岛台 900 + 净距 900 + 桌 800"，并台会牺牲正式用餐。
- **橱柜**：北墙 3000 × 600。
- **岛台**：1800 × 900，中心 (1900, 2150)；与橱柜的**工作通道 1000**（双排口径）；西端到西墙面 900、东端（吧椅背后）到东墙面 900，两端都能绕行。
- **吧椅**：两把 400 × 400，挂在岛台东端（x 2800–3200），椅背朝东、到东墙 900。
- **餐桌**：1400 × 800，中心 (1600, 3900)；桌边到岛台边 **900**；桌西端到西墙面 800（靠墙档），东端到东墙面 1800（主通道）。
- **椅子**：两端各一把 + 北侧两把（推进状态，椅背到岛台 380，只作坐人缝，不作通道）。
- **吊灯**：两盏 300 × 300，吊在岛台三等分处 (1600/2200, 2150)，灯底距台面 800；岛台作业照度靠柜底灯按 [J-LIGHT-02] 的厨房台面档补。
- **主通道**：从南侧推拉门进来 → 餐区东侧 1800 的纵向通道 → 北侧厨房，全程不穿岛台与餐桌之间。

## 判定

`check.run` 应无 error：主通道 ≥ 900、推拉门前 400 内无家具、橱柜/岛台/餐桌互不重叠、吊灯为吸顶件不参与贴墙判定、吧椅与岛台不触发重叠（椅桌例外）。
