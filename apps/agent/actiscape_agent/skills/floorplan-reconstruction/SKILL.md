# 单层户型图忠实复现 · 第三版

适用：清晰单层正交平面图。保留整层结构，只复现用户选定客餐厅的图上布局。原图是证据，墙线检测只是候选。未知项显式阻断，不猜测比例、标注数字或门窗类型。

## 阶段与权限

主控识别并保存像素草稿；检查初审；设计测量并提交对象/字段修改；固定代码应用修改、解算和预检；当前草稿独立审核通过后用户确认；资产匹配真实目录，候选与三维检查通过后由固定代码提交。没有角色拥有任意文件、脚本或正式场景写入工具。

主控与设计都保持连续墙体，用 openings 描述所属墙上的门窗，禁止在洞口处拆成悬空短墙。每个封闭房间只放一个标签。所有目标家具逐件登记，不采用默认数量；原图没有的家具不添加。开放厨房即使与客餐厅相连，用户要求其仅保留结构时，也不登记厨柜和电器。

## 编排与证据

新任务 workflowVersion=3。固定代码先运行 analyze_floorplan，从真实墙色与低饱和灰墙掩膜提取水平和竖直墙带，按共线关系、交点吸附和最大 130px 有证据断口形成完整候选墙；外部尺寸线单独检测并生成代码端点，形成 StructureSkeletonV4。禁止再用整个图像/线条包围盒生成矩形四面墙。结构角色只选择候选墙、洞口和尺寸候选，门窗所属墙、偏移、宽度、尺寸端点与证据由代码生成。首次结构结果无法组装时最多进行一次有界修复。家具阶段先把嵌套轮廓整理为稳定对象候选和主辅活动组候选，强视觉 grounding 角色只分类对象并提交活动组关系；DeepSeek 继续负责结构、测量和常规编排。代码确定性合并两阶段结果后，设计只返回 MeasuredDraftUpdate。人工修改后必须对当前草稿哈希重新审核，旧审核和确认均失效。修改 commands 针对已有对象与字段，附 changeReasons 和 evidenceRefs，不重写整张草稿。

主控最多使用两次局部裁剪，其余两次由设计与检查共享。裁剪身份、原图哈希与坐标变换完整保存并传递图片。相同参数的成功测量可以复用，失败不能作为证据。修改依据按对象及前后状态累计；已有依据只对相同改动有效。首次识别保留供评分，确认前可以依据原图修正误识别；确认后结构与布局冻结。

## 测量与几何

主控调用 analyze_floorplan，读编号墙段、断口、掩膜。设计调用 fit_wall_candidates，引用分析 id 和零起始 segments_px 索引，或实际裁剪内的新视觉候选。采样数多不证明墙语义正确；测量可能测到尺寸线或家具。每项墙特征必须引用匹配该墙中线与厚度的真实测量结果。门窗类型和数量仍须对照图像。

图上明确标注绑定 features 的墙面、中线、墙端或开口边缘，尺寸放入 dimensions，并指向 anchors 中的对应标注。净尺寸与外尺寸要取正确的两侧墙面。TypeScript 在像素观测误差内求解毫米几何，标注为硬约束，像素为观测。最终标注尺寸误差≤1mm；禁止移动像素端点去凑尺寸，禁止任意拉伸X/Y、改数字或删除冲突标注。

measure_dimension_chain 只核对实际相邻标注：N 个刻度配 N-1 个距离，不含累计零点；单段 inconsistent=false 不能证明基准或语义正确。未知层高和墙厚按已披露默认值处理，不能填0或像素厚度到毫米字段。

## 检查与冻结

每轮查看当前原图叠加、实际几何按统一配准回投及代码问题。独立检查逐件核对结构、门窗、房间、家具数量/位置/占地/朝向和功能区，不能仅凭零对账问题通过。检查问题必须引用当前草稿证据和可定位像素框；代码先复核固定洞口、尺寸、轮廓和编译结果，无法复现的模型意见只记为 advisory，不能推翻确定性候选。确认绑定当前草稿哈希；改变草稿会使审核和确认失效。

确认后只进行真实目录匹配，不重排已确认布局。候选须通过数量、目标房间、边界、门前800mm项目净空、明显重叠及有效高度检查，取得俯视和斜视真实截图。原图有冲突则报告，不通过移动墙、门窗或删家具解决。原版 wallaudit、furnoverlay 为启发式证据，不能豁免确定性检查。

所有角色共用24次模型请求、600秒活动时间、初稿后三轮修复；等待确认暂停计时。依据、修改、错误、用量、版本及证据哈希均保留，不能以模拟或人工几何替代真实识别验收。
