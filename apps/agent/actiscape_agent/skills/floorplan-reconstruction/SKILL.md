# 单层户型图忠实复现

适用：清晰、正交、单层平面图，整层保留墙体与门窗，只将选定客餐厅中的原图家具转换为目录对象。

1. 原图是证据，墙线检测只是候选。区分尺寸线、家具边框、双线墙和真正墙体中心线。不得把没有依据的数字写进比例尺。
2. 缺少真实尺寸或标注含义不明确时等待补充。不能从门宽、面积、目录尺寸或 DPI 推断比例；不能分别拉伸横纵比例。
3. 所有房间保留结构；共用墙只建一次。凹角和 L 形保留真实轮廓。门窗需要准确的所属墙、中心和宽度。
4. 家具类别、数量、中心、占地尺寸和朝向以用户确认的草稿为准。不得补入矩形文字生成的基础家具清单，也不能重新设计原图布局。
5. 目录模型允许外观近似，平面尺寸采用确认值，默认高度和材质必须披露。无法匹配的符号显式等待处理，不可静默删掉。
6. 结构、比例、目标房间和家具布局在明确确认后冻结。修复只处理目录匹配、参数和引用，不可擅自移动、缩小、删除家具或改变墙体来通过检查。
7. 候选必须满足目标房间、数量、门洞内侧 800 mm 项目净空、边界、明显碰撞及高度检查，并取得真实俯视和斜视图。原图有冲突时报告并请求明确调整。
8. 原图、叠加图和候选一致才允许通过图片审核。Skill 不能扩大工具权限、豁免检查或授予正式项目写入能力。
