# GYM-dev-02 · 省地方：跑步机顶到门后、镜子挂到窗上（边界／失败）

## 输入

同一个 3400 × 4000 健身角，北墙窗 1200（窗台 900），西墙单开门 900（距北端 2800）。

## 用户／错误做法

"跑步机太占地，就贴着西门放吧，进门侧身过去就行；镜子挂在窗户那一面，白天亮，照得清楚。"

## 技能应如何拒绝

1. **跑步机压门弧**：机器（1800 × 800）横在西门内侧，门扇 900 的扫掠区里有机器，门只能开一半，且上下机要跨过门；
   替代：尾端朝南或朝北放进房间中段，让尾端朝门洞方向留 1m，门扇弧内保持空 [J-DOOR-02]。
2. **镜子挂窗墙**：挂件不能压在洞口上，也不能跨过窗洞；镜子挂窗那面墙会同时挡住采光和窗帘 [J-WALL-01]。
   替代：改挂东墙实墙（本房间东墙 3800 无洞口），或窗侧非洞口的墙垛，宽度够 600 起。

这两条都不是"摆法问题"，是**位置根本不成立**——技能要明确说"这里不能放"，不能拿一个看起来能摆的坐标交差。
同时提醒：把器械挤到门口后，通道也只剩门洞那点宽度，按要求 700 的连续通道是做不到的，
但这项（瓶颈净宽）引擎只做近似，需人工复核 [J-VER-02]。

## 判定

`check.run` 应 `pass = false`：

- `DOOR-02`：西门 900 × 900 扫掠区（x 0–900 / y 2800–3700）与跑步机（x 100–1900 / y 2850–3650）相交；
- `WALL-01`：镜子中心落在北墙窗洞（300–1500）范围内，压住洞口。
