# 预期结果

- `check.run`：**pass = false**。
- 必须出现：
  - `DOOR-02`（门扇开启范围内有家具）：西门的门扇扫掠矩形与 `o_treadmill` 相交；
  - `WALL-01`（挂墙件压洞口）：`o_mirror` 的中心在窗洞 `win1` 的 300–1500 区间内。
- 不应出现：`CIR-02`、`OVER-01`、`CUR-01`、`WIN-01`。
  （门洞本身还有 100 深的落脚格，所以不是"门口被堵"；两件器械不重叠；镜子是挂墙件，不参与窗帘带与高柜挡窗判定。）

# 说明

这个案例不是"技能做错了"，而是**技能必须能识别并拒绝**的输入。
它证明两件事：

1. 门扇弧与挂墙件位置真的会被引擎拦下来，技能里写的"器械不挡门""镜子只挂实墙"有执行依据；
2. "尾端 1m / 两侧 0.5m"这类**经验安全距**不在判据库、也不在引擎里，本案例只能证明它压了门弧，
   不能证明"尾端 1m"被检查到了——这一项要人工复核，交付时必须写明。

# 失效即表示

- 引擎没报 `DOOR-02`：门扇矩形或 `blocks_floor` 口径有问题；
- 引擎没报 `WALL-01`：挂墙件与洞口的区间判定有问题（容差 50）；
- 若引擎反而报了 `CIR-02`：说明门洞落脚格判定过严，会与"门口 300 内必须有自由格"的设计冲突。
