# KID-dev-01 · 9.5㎡ 儿童房，学龄期（正向）

## 输入

- 场景：矩形儿童房，轴线 3000 × 3600 mm，墙厚 200，内净约 9.5㎡（轴线 10.8㎡）。
- 洞口：
  - 北墙平开窗，宽 1000（距西端 800），窗台高 900；
  - 南墙单开门，宽 900（距西端 1700），向内开。
- 孩子 7 岁，身高 1.2m；家长原话："要能写作业的桌子、一个衣柜，剩下的地方给他玩；
  以后他长大了这间房还得能用。"

## 已知约束

- 床 1200×2000（单人），床头靠南墙，床一侧靠西墙；
- 书桌 1000×600，要侧光，不要正对窗（避免屏幕/纸面反光），桌前要能推椅子；
- 窗下与窗内侧带不能放高柜；
- 高柜必须能固定到实墙；活动区用可卷起的地垫，不占固定家具。

## 判定

`check.run` 应无 error；再由人工复核：

- 桌前使用区：椅背后 y 1210–2110 连续空着，够转身与推椅 [J-CIR-05]；
- 书桌离窗留 900 侧向距离，窗在左前方，写字不背光；桌面照度另配台灯 [J-LIGHT-02]；
- 床东侧 1300–2900 通长区域不被家具切断 [J-CIR-01]；
- 房间面积满足单人卧室下限 [J-STA-01]；
- 高柜（衣柜）靠实墙、避开门扇与窗带，交付清单里写明"必须上墙固定"（安全项，人工确认）。
