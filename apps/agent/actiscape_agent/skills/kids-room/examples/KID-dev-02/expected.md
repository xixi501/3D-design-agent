# 边界案例要证明什么

1. "挤一点没关系"在几何上会先变成"重叠"，而不是"变窄"——重叠是硬错，必须拦住；
2. 本例只有一个重叠对（书桌 × 床），椅子在床东沿之外、地垫是非阻挡件，所以只应报一条；
3. 拦住之后必须给出替代方案（窄桌、上下床、过渡方案），而不是让用户自己想办法 [J-VER-02] 的修复预算也用在这里：
   自动修复只在坐标层面重试，不重复"生成—检查"到通过。

# 失效即表示

- 报了两条以上 `OVER-01`：说明椅子或地垫也被算成重叠，坐标超出预期（椅子应在床东沿 1300 之外）；
- 报 `CIR-02`：书桌把门口到床东侧的通道也切断了，那是另一类错误；
- 没报 `OVER-01`：重叠判定或容差被改动（本例重叠面积 600×850，远超容差），先查引擎。
