# KIT-dev-01 · 2.7 × 3.3m 的 L 形厨房（正向）

## 输入

- 场景：矩形厨房，轴线 2700 × 3300 mm，墙厚 200，内净约 7.75㎡（轴线面积 8.91㎡）。
- 洞口：
  - 东墙平开窗，宽 1200（距北端 600），窗台高 900、窗头 2100；
  - 南墙单开门，宽 900（距西端 400），向室内开。
- 用户原话："三口人，天天做饭，冰箱想放门口那侧，别挡窗户。"
- 已知：燃气灶在北墙偏西（原立管位置），下水在东墙北段。

## 技能给出的方案

- **选形**：开间 2700，按选形表走 L 形（不做 U：进深 3300 扣两排柜与端头柜后通道只剩约 500）。
- **柜体**：北墙地柜 2400 × 600（含灶台与切配），西墙地柜 1500 × 600（转角与盛盘），转角不重叠（两段柜各占各的区间）。
- **家电**：冰箱 700 × 700 落在东南角、门朝西（开门侧净空约 1200）；油烟机贴北墙、压在灶台上方；微波炉落在西墙短台面上。
- **备餐顺序**：冰箱（取）→ 北墙东端水槽（洗）→ 中段切配（切）→ 西段灶台（炒）→ 西墙短台面（盛）。
- **操作三角**：冰箱 (2250, 2400) → 水槽 (2200, 400) → 灶台 (800, 400)，三边约 2000 / 1400 / 2470 mm，合计约 5.9m。
- **窗**：吊柜只做在北墙，窗洞范围内一棵不留；冰箱与高柜都退出窗前 400。

## 判定

`check.run` 应无 error：通道 ≥ 900（东门可走到北侧灶台区与西侧转角）、窗内侧 150 无 h > 600 的家具、冰箱不在窗前 400、门扇 900 × 900 开启区内无家具、微波炉落在台面投影内。
