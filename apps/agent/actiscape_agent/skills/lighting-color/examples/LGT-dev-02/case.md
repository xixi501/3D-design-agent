# LGT-dev-02 · 落地灯放进门的开启范围（边界／失败）

## 输入

同 LGT-dev-01 的 4200 × 5400 客餐厅：北窗 2400、西墙 900 门（y 800–1700）、餐区在北、客厅在南。

## 用户／错误做法

"进门得有个亮，把落地灯放在门边（500, 1200），一开门就看见光。"

落地灯 400 × 400 的中心落在 (500, 1200)，整盏灯压在 900 × 900 的门扇扫掠区里：
门开到 90° 会撞灯，门只能开一半，进出要侧身。

## 技能应如何反应

改灯位，不改门：

1. 落地灯挪到门侧 400 以外（如 (1400, 1200)），或挪到餐桌西侧；
2. 需要"进门就有光"时改用壁灯（贴墙、门上 150–200、避开洞口），或把环境筒灯靠门加一盏；
3. 说明原因：门扇扫掠区内不得有落地家具，落地灯属于落地家具。

## 判定

`check.run` 应报 `DOOR-02`；技能不得把该方案标为已完成，也不得靠缩小门宽来"通过"。
