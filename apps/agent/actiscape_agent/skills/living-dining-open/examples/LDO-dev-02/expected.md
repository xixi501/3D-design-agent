# 预期结果

- `check.run`：**pass = false**。
- `must_trigger`：`CIR-02`（判据 [J-CIR-02]）——门与房间主要区域之间不连通。
- 期望同时不出现：`OVER-01`（三段柜体只是首尾相接，不是重叠）、`DOOR-02`（柜带离北门 2.4m）、
  `CUR-01` / `WIN-01`（柜带不在南窗的窗内侧带里）。
- 引擎实测信息：`从门口只能到达 17% 的通行区域`（阈值判定见 [J-CIR-02]）。

# 边界案例要证明什么

1. 引擎确实把"墙到墙的分区带"识别成动线切断，而不是当成好看的造型放过；
2. 技能正文里"半岛两端必须留通道、先保环线再谈分区"这条判断，对应的检查真实存在；
3. 修复方向明确：把东段餐边柜从 1900 缩到 ≤1600（东端留出 ≥700），或把整条带子南移 300 并缩短西段，
   让两端各出现一条通长通道——不需要重画整个方案。

# 失效即表示

- 引擎没有报 `CIR-02`：说明通行判定口径变了（先查 min_passage 与栅格），不能改期望来凑；
- 或报出 `OVER-01`：说明三段柜体的搭接坐标写错了（本例应当是首尾相接、不重叠）。
