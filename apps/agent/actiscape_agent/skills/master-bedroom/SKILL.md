# 主卧：睡眠区、收纳与梳妆取舍

> v1 接入说明：本 Skill 只声明语义 capability，不能直接写正式场景、提交项目或执行任意脚本。所有修改必须形成候选，并由固定代码预检、渲染、审核和提交。

## 什么时候用

✅ 适用：

- 主卧使用面积 10–20㎡，已有一版含墙体门窗的快照；
- 用户给了床的规格（1.5 或 1.8）与衣柜需求，或问"能不能再加梳妆台/电视"；
- 需要判断"哪面墙做床头"、"衣柜放哪面墙不挡路"。

❌ 不适用（转其他技能）：

- 儿童房、老人房、保姆间：转 `kids-room` 或 `aging-friendly`，安全项完全不同；
- 主卧带独立衣帽间或卫浴套间：先由 `bathroom-standard` 或收纳技能定内隔，再回到本技能；
- 需要改门洞、加窗、动水电点位：超出本技能，交回主控。

开工前只问三件事：

1. 床是 1.5 还是 1.8（1.8 会直接吃掉两侧通道的余量）；
2. 衣柜要平开门还是推拉门（决定柜前要留多少）；
3. 电视、梳妆台、书桌，三选一还是都不要（三个都要，10–20㎡ 基本放不下）。

## 怎么做

**第 1 步 · 选床头墙**
`scene.read` 取墙与洞口，按三条筛床头墙：

1. 连续实墙、长度够"床宽 + 两侧床头柜 + 余量"；
2. 不正对卧室门（进门先看到床尾或衣柜侧面，而不是床头正面）；
3. 床头墙尽量不要是窗墙——床头压在窗下会让窗帘、窗台、暖气三件事同时失效。
   三条冲突时，优先"不正对门"，其次"是实墙"，最后才妥协窗墙（并在交付里写明代价）。

**第 2 步 · 床与两侧通道**

- 床居中于床头墙，两侧床头柜各自离床 50 左右，别贴死（贴死就没法换床单）；
- 两侧通道按 [J-CIR-04] 取，双人床尽量对称；一侧被衣柜或墙压到不足时，把床整体偏移而不是缩小通道；
- 床尾到对面墙或柜按 [J-CIR-08] 取；床尾放床尾凳时，凳的外沿算进这条净距。

**第 3 步 · 衣柜：先定柜前净空，再定柜长**
衣柜的可用长度由"墙段长度 − 门扇扫掠 − 转角余量"决定，不由柜子型号决定。
柜前净空按柜门类型取 [J-CIR-06]（平开门比推拉门苛刻得多）；净空不够时按顺序让步：
① 换推拉门；② 减柜宽；③ 换位置；④ 才考虑缩床。**不要**用"柜门只开一半"来凑。

**第 4 步 · 梳妆 / 电视的取舍（本技能的核心判断）**

| 取舍         | 选衣柜               | 选梳妆台               | 选电视                    |
| ------------ | -------------------- | ---------------------- | ------------------------- |
| 需要的内宽   | 柜深 + 柜前净空      | 桌深 + 座位后 750      | 床尾净距 + 走线           |
| 什么时候成立 | 收纳是刚需，几乎总是 | 有自然光侧位且宽度富余 | 床尾有 ≥1.2m 且不做整墙柜 |
| 代价         | 化妆要另找光源       | 少一排挂衣             | 床尾净距被吃掉，走道变窄  |
| 本技能默认   | ✅ 首选              | 只在宽度富余时加       | 只在衣柜已解决后考虑      |

三条实操结论：梳妆台可以与衣柜合并（柜内抽拉镜 + 柜侧灯）；电视挂墙比放电视柜省 400 深；
梳妆台的正前方必须避开窗（背光化妆会失真），镜子不要正对床。

**第 5 步 · 窗、窗帘与窗下净空**

- 窗帘盖满窗洞、两侧各多 100–200，落地款才压得住大窗；
- 窗内侧带内不放高于 600 的落地家具，窗帘才拉得动 [J-CUR-01]；
- 床头不压窗时，窗下适合放矮柜、斗柜或什么都不放；床头压窗时改用短帘（窗台以上）并把床头退离窗 300 以上；
- 窗在东/西墙时注意床侧通道与窗帘的抢位：窗帘收起来也要占 150 左右。

**第 6 步 · 门、重叠与台面件**

- 衣柜、梳妆台、床尾凳任何一件进到门扇扫掠区，门就废了 [J-DOOR-02]；
- 落地家具两两不重叠，床头柜与床之间留缝，床尾凳贴床是允许的例外 [J-OVER-01]；
- 床头灯、闹钟这类台面件必须完整落在床头柜台面内 [J-ASSET-02]；
- 主家具长度不超过所在墙长的 2/3（衣柜 2000 的柜子需要 ≥3000 的墙）[J-PROP-01]；
- 房间面积要满足下限，主卧不能靠"兼起居"的名义缩面积 [J-STA-01]。

**第 7 步 · 光**
主卧照度按 [J-LIGHT-02] 的卧室档，别把客厅的亮度搬进来；床头两盏可独立开关的灯比一盏顶灯好用（起夜不吵人）。

**第 8 步 · 提交与检查**
先提"床 + 床头柜"，检查；再提"衣柜"，检查；最后提"软装与灯具"。
每轮只改被点到的对象 [J-VER-01]；自动修复最多 3 轮，仍不过的写进未解决清单 [J-VER-02]。

- 没有 `scene.*`：给文字坐标方案（床/柜的中心点、朝向、外沿到墙面内皮的净值）+ 一张手绘平面描述；
- 没有 `candidate.preflight / candidate.review`：按第 3、6 步逐条手算，并在交付里注明"未经工具检查"。

## 怎么验证

- **正向** `MBR-dev-01`：3600 × 4200 主卧（内净约 13.6㎡），床头贴北墙（无洞口、不正对门），
  两侧床头柜、床尾凳、南墙西段 2000 衣柜、东窗落地窗帘、床头挂画与台灯。
  期望 `candidate.preflight / candidate.review` 全通过：门扇区让开衣柜、窗内侧带无高柜、台灯压在柜面内。
- **边界** `MBR-dev-02`：把衣柜放到"进门右手边"，柜体越进门洞西沿，压掉 600 深的门扇扫掠区。
  期望报 `DOOR-02`，技能应拒绝并给出"西移 / 减宽 / 换推拉门"三条替代。

两个案例都在 `examples/` 下，`ops.json` 可被 mock 引擎复跑。
