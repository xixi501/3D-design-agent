# MBR-dev-02 · 15㎡ 主卧（边界：进门右手边做衣柜，挡住门扇）

## 输入

- 场景与 MBR-dev-01 相同（3600 × 4200，东窗 1200，南门 900，门距西端 2200）。
- 床、两个床头柜、床尾凳、窗帘已按正向案例摆好。
- 用户原话："衣柜就放进门右手边那面墙，一进门顺手挂衣服，走廊也不占。"

## 已知约束

- 南墙从 x=100 到门洞 2200 只有 2100 的连续段；
- 衣柜 2000×600 平开门，柜前要能站人开门；
- 门是向内开的单开门，门扇扫掠区为门洞宽 × 门洞宽；
- 承重墙与洞口不动。

## 技能给出的方案（错误示范，应被拒绝）

```json
{
  "op": "add",
  "object": {
    "id": "o_ward",
    "key": "wardrobe",
    "at": [2200, 3700],
    "rot": 0,
    "w": 2000,
    "d": 600
  }
}
```

中心 (2200, 3700)，实际占位 x 1200–3200、y 3400–4000。
它把"进门右手边"理解成"贴着门洞放"，柜体东端 3200 越过门洞西沿 2200，
整条 900 宽的门扇扫掠区（x 2200–3100、y 3300–4200）里有 600 深被柜体占掉。

## 判定

`check.run` 必须报 `DOOR-02`，`pass = false`：门扇开启范围内有家具，门只能开一条缝。

技能的正确反应：把衣柜西移，让它东端停在门洞西沿之外（正向案例的 (1100, 3700)，
柜东端 2100 < 2200），柜前净空仍然大于平开门所需 [J-CIR-06]；
如果墙段实在不够，就把衣柜减宽（2000 → 1600）或改推拉门衣柜，而不是压门扇。
