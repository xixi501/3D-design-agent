# MED-dev-02 · 把设备柜挪到东窗前（边界／失败）

## 输入

同一个 4200 × 5000 影音室：东墙窗 1800 宽（窗台 700，距北端 1500）、西墙门 900 宽。

## 用户／错误做法

"设备柜挪到东窗前面，走线最短，柜顶还能放投影仪。"

设备柜 1200 × 400、高 2.4m，整个柜体压在东窗的窗下位置（柜背贴东墙）。

## 技能应如何反应

拒绝，并给出替代：

1. 设备柜回西墙无窗段（本案例正向方案的位置），走线改从地脚/踢脚线走；
2. 或改矮柜（柜面低于窗台）放在窗下，高柜移到南墙无窗段；
3. 说明原因：窗内侧 150 为窗帘活动区，2.4m 高的柜体会把整幅窗帘顶死 [J-CUR-01]；窗台 700 以下的窗前 400 内不放高于窗台的柜体 [J-WIN-01]；同时柜子挡光，白天看电影的遮光方案直接失效。

## 判定

`check.run` 应报 `CUR-01`（窗帘活动区）与 `WIN-01`（高柜挡窗）；技能不得把该方案标为已完成。
