# 预期结果

- `check.run`：**pass = false**。
- 必须出现：`CUR-01` —— 婴儿床（x 2175–2875 / y 125–1375，h=950）与东窗内侧 150 条带
  （x 2850–3000 / y 300–1200）相交。
- 不应出现：`CIR-02`、`DOOR-02`、`OVER-01`、`WIN-01`、`WALL-01`、`ASSET-02`。
  （房间仍可从门口走通；门弧内无家具；床与尿布台 y 向留 125；婴儿床不属于柜类所以不触发 WIN-01；
  没有挂墙件。）

# 说明

这个案例是婴儿房最典型的"看起来合理"的错误：通风、采光、看风景三条都对，
但对婴儿来说窗下是冷桥 + 风口 + 窗帘绳，而且床贴墙后只剩单侧通道。
引擎只抓得住其中一条（窗帘带），另外三条必须由技能在交付里点出来，**不能因为"只报了一个错"就放过**。

同时注意：本案例的 `must_not_trigger` 里有 `WIN-01`，是为了证明 `crib` 没有被误归为"柜类"；
若引擎报了 `WIN-01`，说明分类表要修，不是期望该改。

# 失效即表示

- 不报 `CUR-01`：窗帘带选错了窗（东墙 `win1`）或 h 阈值判错（床 950 > 600）；
- 报了 `WIN-01`：`crib` 被误归入柜类；
- 报了 `OVER-01`：床与 `curtain` 的"平铺/软装"例外没生效（窗帘不应参与重叠）。
