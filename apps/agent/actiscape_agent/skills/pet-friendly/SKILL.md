# 宠物家庭布置

> v1 接入说明：本 Skill 只声明语义 capability，不能直接写正式场景、提交项目或执行任意脚本。所有修改必须形成候选，并由固定代码预检、渲染、审核和提交。

## 什么时候用

✅ 适用：

- 家里有猫或狗（1–2 只），要在客厅/起居空间里安排宠物用品；
- 用户抱怨"猫爬架挡路""猫砂盆味道大""沙发被抓""狗窝在走道中间"；
- 正在选家具与地面材料，需要"耐抓耐污"的取舍建议。

❌ 不适用（转其他技能）：

- 需要拆改、加隔断、做独立宠物房：超出本技能；
- 需要全屋除味/新风/排水改造：交回主控，本技能只做位置与材料；
- 纯收纳问题、无宠物：转 `entry-storage` 或 `living-dining-small`。

开工前必须问清三件事（问不到按保守值）：

1. 猫还是狗、几只、体重（决定猫爬架稳定性与狗窝尺寸）；
2. 猫砂盆/狗厕所现在放哪、味道能不能接受（决定能否移位）；
3. 宠物是否上床/上沙发（决定面料与是否需要可拆洗套）。

## 怎么做

**第 1 步 · 先划两块"宠物专用"**

- **活动区**（猫爬架或狗窝）≥ 0.6 × 0.6，猫还要垂直空间，爬架高度 ≥1200；
- **清洁点**（猫砂盆/狗厕所 + 防带砂垫 + 垃圾桶）靠通风、靠水源、**远离餐厨与床头**；
- 两块都不得占用主通道，也不得切断门与主区 [J-CIR-02]；主通道仍按 ≥700 [J-CIR-01]。

**第 2 步 · 猫爬架：靠窗，但不进窗帘带**

- 首选**窗侧墙段**而非窗洞正下方：晒太阳是猫的核心需求，但落地窗帘要能拉动 [J-CUR-01]；
- 爬架底座要压得住（自重 + 防倾倒固定），顶层平台离地 1200–1600；
- 爬架到沙发/柜 ≥300，留出跳落与转身；不要在爬架与墙之间留 100 的死缝（猫会卡、也扫不到）。
- 窗下如果要放东西，只放**低于 600** 的坐垫/矮柜；高于 600 的落地件不进窗内侧 150 [J-CUR-01]。

**第 3 步 · 猫砂盆/狗窝：位置比款式重要**

- 猫砂盆：远离餐厨 ≥1500、远离床头；盆前留 ≥600 转身与清理空间；盆下垫防带砂垫（可水洗）；
- 狗窝：不放在门口正对处（冲门、被踩），不放在主动线转角；窝边留 ≥600 让狗转身躺下；
- 多猫要"盆数 = 猫数 + 1"，位置分散，不要并排成一条走廊。

**第 4 步 · 材料：按"抓、挠、尿、掉毛"四件事选**

- 地面：耐磨等级 AC4 以上，或石塑/瓷砖；长毛地毯只做小块可机洗，不做满铺；
- 沙发：可拆洗套 + 高密度织物（猫抓布/超纤），避免真皮（抓痕不可逆）与粗编织（勾爪）；
- 柜体：封闭收纳，宠物粮与清洁剂放柜内并加儿童锁式卡扣；
- 同一空间主材 ≤3 种，方便补货与局部更换 [J-COL-02]。

**第 5 步 · 动线避让与门挡**

- 门挡/宠物门栏放在**玄关与客厅之间**，形成"拦截带"，避免宠物冲门；
- 家具之间不留 100–200 的窄缝（猫会钻、扫地机进不去）；
- 猫砂盆与食盆分开 ≥1000（猫不喜欢在厕所边进食）；
- 走道上的宠物窝要能整体挪走，不做固定地台。

**第 6 步 · 电线与易碎品**

- 踢脚线走线槽，落地灯/加湿器电源线贴墙收进线槽；
- 易碎品与绿植放到 ≥1200 的搁板或封闭柜内；猫爬架顶层不要正对搁板（起跳会撞落）；
- 窗帘选无绳或短绳款，避免缠绕。

**第 7 步 · 提交与检查**

1. 先提交沙发、地毯、宠物活动区三件，`candidate.propose + candidate.preflight` 带 `base_version`；
2. `candidate.preflight / candidate.review` 看通道、窗帘带、重叠；再提交清洁点与收纳；
3. 最多 3 轮修复 [J-VER-02]；未解决项如实写进清单；
4. 只改本次涉及的对象，户型与既有家具不动 [J-VER-01]。

未适配时的降级路径（状态仍为 `pending_adaptation`）：

- 没有 `scene.*`：给文字坐标表 + 材料清单，由主控转场景；
- catalog 没有猫砂盆/狗窝 key：用 `petBed` 等效占位并标注"需 asset.job 换真实件"，不假装已落位。

## 怎么验证

- **正向** `PET-dev-01`：4.2×5.6m 起居室（轴线 23.5㎡，净约 21.6㎡）。沙发靠南、茶几距 450、地毯；猫爬架放在北窗东侧的墙段（避开窗内侧 150），宠物床在沙发东侧留 150；宠物用品柜贴西墙避开门扇；门口防带砂垫。期望 `candidate.preflight / candidate.review` 全通过。
- **边界** `PET-dev-02`：把 1600 高的猫爬架放到窗洞正下方。期望报 `CUR-01`（窗内侧 150 内有 h>600 的落地家具）。技能应把它挪到窗侧墙段，而不是把窗帘拆了。

两个案例在 `examples/` 下；L1/L2 结果回填 `manifest.validation`。
