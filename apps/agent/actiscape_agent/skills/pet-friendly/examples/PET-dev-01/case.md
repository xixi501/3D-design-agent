# PET-dev-01 · 23.5㎡ 猫狗同住起居室（正向）

## 输入

- 场景：矩形起居室，轴线 4200 × 5600 mm，墙厚 200，净约 21.6㎡。
- 洞口：
  - 西墙入户门，宽 900（距南墙 3800），内开；
  - 北墙平开窗，宽 2000（距西墙 1000），窗台高 900。
- 用户原话："一猫一狗，猫爱晒太阳但窗帘总是被抓；狗窝原来在走道中间，天天绊脚；猫砂盆放餐厅边上味道受不了。"

## 已知约束

- 猫爬架要靠窗，但不能进窗帘活动区；狗窝与猫砂盆避开主动线；
- 沙发要可拆洗、耐抓；地面耐磨；同空间主材 ≤3 种；
- 保 700 通行，门口留防带砂垫与拦截带。

## 技能给出的方案

- 会客组：2200 沙发靠南墙，1200×600 茶几距沙发 450，2000×1700 地毯；
- 猫爬架（600×600，h1600）放在北窗**东侧墙段**，退出窗内侧 150；
- 狗窝（700×550）放沙发东侧、留 150 与沙发脱开，不占门到客厅的通道；
- 宠物用品柜（1200×400，h2400）贴西墙北段，避开门扇；
- 玄关防带砂垫 900×600；北窗 2400 落地帘，窗帘带内只放低矮件；
- 绿植（h1400）放在东墙北段，与猫爬架隔 450（不被起跳撞落）。

## 判定

`check.run` 应无 error：700 通道、门扇开启区、窗帘带 150、无重叠、挂墙件不压洞口。
