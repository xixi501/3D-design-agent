# PET-dev-02 · 猫爬架放在窗下（边界／失败）

## 输入

同一个 4200 × 5600 起居室：北墙窗 2000 宽、窗台 900；西墙入户门。

## 用户／错误做法

"猫爬架就靠着窗放，猫最喜欢看外面；窗帘拉一半就行。"
结果：1600 高的猫爬架几乎顶到窗洞，窗内侧 150 的活动带被占掉。

## 技能应如何反应

拒绝这个位置，并给出替代：

1. 挪到窗**东侧墙段**（窗洞外 200 以上），既能看到外面，也不压窗帘带；
2. 或换成矮于 600 的窗台坐垫/猫窝，窗下只留低件；
3. 说明原因：窗内侧 150 是窗帘活动区，h>600 的落地家具在那里会让帘子拉不动 [J-CUR-01]。

## 判定

`check.run` 应报 `CUR-01`（窗内侧 150 内有 h>600 的落地家具）。
不应报 `WIN-01`：猫爬架不是柜类，这条检查管的是"高柜挡窗"，不是宠物爬架。
