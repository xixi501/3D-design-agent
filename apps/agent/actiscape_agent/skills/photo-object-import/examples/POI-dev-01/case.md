# POI-dev-01 · 花瓶落到茶几上（正向）

## 输入

- 场景：4000 × 5000 客餐厅，西墙单开门（宽 900，距北端 3800），场景里已有一张 1200 × 600 茶几（`o_table`，中心 2000, 2500）。
- 用户：上传一张花瓶照片，说"高大概 35 厘米，放到茶几上"。

## 技能应做的事

1. 提交资产作业（`request_id` 唯一，重复点击复用）；
2. 轮询状态，生成完给用户看预览；
3. 用户确认外观；尺寸按用户口述 350 高、口径 180 记入（标注"用户确认，非实测"）；
4. 落点：语言"放到茶几上"→ 匹配到 `o_table`；提交 `add`，带 `on: "o_table"`；
5. 检查支撑面包含、与台面已有物品不重叠、不挡通道。

## 判定

`check.run` 通过（无 `ASSET-02`、无 `OVER-01`、无 `CIR-01`）。
