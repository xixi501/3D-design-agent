# 矩形客餐厅与阅读会客组合

适用：已确认净宽、净深、入口、窗的单个矩形室内空间。只布置真实目录家具，不改变结构。

## 共同规则

- 所有实际坐标和尺寸采用 TypeScript 预览返回的毫米值，室内范围为 x=0..净宽、y=0..净深。x 向右，y 向下。用户给出的净尺寸和门窗不可因家具放不下而改变。
- 用 search_catalogue_batch 一次查询完整家具清单，按真实 key 与尺寸选型。三人沙发不能换成单人椅，书柜不能用杂物柜凑数，明确的数量不能减少。
- rot=0 背靠上方，90 背靠右侧，180 背靠下方，270 背靠左侧。靠墙家具中心距墙内皮至少为旋转后实际占地的一半；不要把中心直接放在墙面上。
- 门洞内侧 800 mm 范围保持无家具遮挡。优先保留入口和主要活动区域的空地；该值是本项目布局规则，不等同于规范检查或完整通路分析。
- 先调用 precheck_initialization 检查完整方案。数量、越界、重叠或净空失败时，根据实际对象和报告调整家具位置与朝向，不扩大房间或移动门窗。
- 用户没有要求缩小家具时，使用目录默认尺寸。若默认尺寸放不下，在有限修复后说明问题并询问用户，不偷偷缩成不合理的小家具。
- 风格未指定时，用中性墙面、木色地面与柔和家具颜色；明确配色要求需满足。不要加入未要求的灯光、全景或日照能力。

## 客餐厅

- 未指定家具时，基础清单为三人沙发、茶几、电视柜、餐桌各一，餐椅四把、落地灯一盏。
- 把沙发与电视柜相向组织，茶几在会客区中间；餐桌与四把餐椅组成独立用餐区，桌椅须按各自真实尺寸摆放，避免重叠。
- 沙发长边优先沿较长的空墙，避免压住窗或入口；落地灯放沙发一侧并留出占地。

## 阅读会客间

- 未指定家具时，基础清单为两把单人沙发、茶几、书柜和落地灯各一。
- 两把单人沙发应形成能交流的组合，可相向或呈夹角；茶几放在其间，保留彼此占地。
- 阅读座位优先接近采光侧但避开窗洞占地；书柜靠空墙，落地灯放阅读座位旁边。设计说明指出哪把座位承担主要阅读用途，便于后续引用。

## 独立检查

- 调用 candidate_checks，并结合固定俯视与斜视图核对需求、家具数量、门窗、尺寸、朝向和明显穿插。
- 区分本次新增数量与全场数量；不能因画面好看而忽略代码阻断项。
- 证据不足、需求无法满足或反复失败时返回明确问题，不声明已保存。

本技能整理自固定上游 HouseSpec 格式与家具朝向说明，并加入 ActiScape 的候选与入口净空规则。它是设计指导，不能赋予新的写权限。
