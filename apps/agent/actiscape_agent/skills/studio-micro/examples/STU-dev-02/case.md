# STU-dev-02 · 床堵住入户门（边界／失败）

## 输入

同一个 4000 × 7000 开间：北墙入户门 900、东墙窗 1600；空场景。

## 用户／错误做法

"床往门口推一点，床尾就能留出 450 放书架；床头柜也塞得下了。"
结果：1800 床贴到北墙，门口 300 的落脚带被床体压住；书架离床尾 450。

## 技能应如何反应

拒绝这个位置，并把床退回：

1. 床头离门洞内边 ≥ 900（门扇开启区），且门口 300 落脚带必须为空；
2. 450 不是通道，是侧身余量；开间主通道 ≥700 [J-CIR-01]；
3. 书架要 450 的话，改放到床尾侧面（顺墙）而不是把床往前顶。

## 判定

`check.run` 应报 `CIR-02`（门口落脚带被床占满，门到房间主区不通）。
同一位置也落在门扇扫掠内，会同时报 `DOOR-02`——这不是两条独立错误，而是同一个错误位置的两个后果，技能应一并指出。
