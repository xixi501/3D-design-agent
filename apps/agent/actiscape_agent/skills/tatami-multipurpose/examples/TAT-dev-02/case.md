# TAT-dev-02 · 把地台做到门口（边界／失败）

## 输入

同一个 2800 × 3400 多功能房：北墙窗 1200 宽（窗台 450），东墙单开门 900 宽（距北端 2200），门扇向室内开、铰链在洞口北端。

## 用户／错误做法

"地台直接做到门口，进来就上台阶，多一块收纳；反正门开一点点就够进人了。"

地台 2000 × 2000 南移到门口，台面矮桌仍放在台面上。

## 技能应如何反应

拒绝，并给出替代：

1. 门口做 900 宽落尘区（不铺台），地台从门扇开启区之后起——本案例正向方案的做法；
2. 或改推拉/折叠门并把地面做平，让台体退出 400 的推拉门前条带 [J-DOOR-01]；
3. 说明原因：门宽 × 门宽的门扇扫掠区内不得有落地家具 [J-DOOR-02]；地台压进去，门的开启角就只剩一半，柜体和台面会互相碰。

## 判定

`check.run` 应报 `DOOR-02`（地台落在 900 × 900 门扇开启区内）；技能不得把该方案标为已完成。
