# 预期结果

- `check.run`：**pass = false**；
- 必须出现：`DOOR-02`（地台落在 900 × 900 的门扇开启区内，门只能开一半）；
- 不应出现：`CUR-01`、`WIN-01`（地台南移到 y = 1200–3200，已离开窗内侧 150 条带）、`OVER-01`（矮桌带 `on`，与地台不算重叠）、`ASSET-02`（矮桌在台面投影内）、`DOOR-01`（本案例是平开门，不是推拉/折叠门）。

# 说明

这个案例不是"技能做错了"，而是**技能必须能识别并拒绝**的输入。它证明两件事：

1. 地台在引擎里被当作落地家具，会真的被门扇检查拦住，而不是"反正台面低、不算家具"；
2. 门口通行没被切断（`CIR-02` 不报），说明拦截来自门扇开启而非"门口被堵"——技能里"门口留落尘区"的理由是可复现的。
