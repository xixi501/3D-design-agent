# UTL-dev-01 · 4.7㎡ 家政间（正向）

## 输入

- 场景：矩形小间，轴线 1800 × 2600 mm，墙厚 200，内净约 4.7㎡（内净 1600 × 2400）。
- 洞口：南墙单开门，宽 800（距西端 900 → 1700），向室内开。
- 用户原话："洗衣机烘干机并排，拖把池想要一个，纸巾清洁剂囤半年的量，扫拖一体机也得充电，
  门打开别撞柜子。"

## 已知约束

- 洗烘并排占 1200 墙面（各 600），前留 700 操作面。
- 房间净宽 1600 → 只用 400 浅柜，不做 600 标准柜；主通道按 700 设计。
- 门是平开：门扇 800 × 800 弧内只能空着，门后只允许挂薄挂具。
- 扫地机基站靠墙、正面朝外、电源同侧。
- 无窗，靠排风扇 + 柜体离地 100 防潮。

## 判定

`check.run` 应无 error：

- 门扇 800 × 800 扫掠区（x 900–1700 / y 1700–2500）内无落地家具；
- 洞洞板贴西墙（离墙中线 150，容差 180 内）且不压洞口；
- 洗烘、高柜、拖把池、基站落地投影互不重叠；
- 高柜南端 y=1300 到南墙内皮 2500 → 1200 的开放端头（≥600），最里端囤货能拿到；
- 门口 300 深范围内有自由落脚格（房间 <6㎡，引擎只查这一条，通道靠人工复核）。

人工核对：排水存水弯与专用地漏、排风量、柜体离地 100、基站前方 500、洗烘前 700。
