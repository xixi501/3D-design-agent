# VIL-dev-02 · 入户门被鞋柜挡住（边界／失败）

## 输入

同一个 8000 × 12000 首层：南墙入户门 1000、北墙推拉门 1800 + 窗 2600、西墙窗 3000；空场景。

## 用户／错误做法

"鞋柜贴着门后放，离门 450 刚好够开门；玄关小，只能这么塞。"

## 技能应如何反应

拒绝这个位置，并给出替代：

1. 鞋柜移到门侧实墙（门洞外 ≥100），保门扇开启区内无家具 [J-DOOR-02]；
2. 入户门扇开启后净宽仍要 ≥900，鞋柜深 350 不要加深 [J-ENT-01]；
3. 玄关太短时先压缩换鞋凳（可折叠），不要压缩门扇开启区。

## 判定

`check.run` 应报 `DOOR-02`（门扇扫掠范围内有家具）。
本例不应报 `CIR-02`：鞋柜只压门扇，没有占满门口 300 的落脚带，门到主区仍连通——两者要分清。
