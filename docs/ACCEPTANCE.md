## 核心流程验收细节

- **数据与导入**：原版完整快照逐字段一致，已有对象 ID 保留；HouseSpec 在身份规范化后与原版完整业务数据一致。多楼层明确拒绝，缺失 GLB 列出引用并经文件映射后导入。
- **手工编辑**：真实鼠标拖动、旋转、复制，柜体分格与副本独立编辑，自由造型切换、轮廓顶点拖动与阵列，橱柜形状、分段吊柜、房间材质与铺砖。二维、分屏、三维可切换，三维点选和拖动映射到正确业务对象。
- **历史**：多次撤销/重做、撤销后分支清理、200 个编辑事务上限、审计记录保留、浏览器重开和服务重启后继续历史操作。
- **资产**：真实带贴图 GLB 上传，尺寸/旋转/离地修改，干净浏览器通过项目链接恢复模型与贴图。旧项目中的二维颜色不改变 GLB 原材质；显式颜色叠加与撤销也已验证。
- **并发与失败**：过期版本拒绝、相同操作去重、相同身份不同内容冲突、批次中途失败回滚、模拟数据库写入失败回滚。两个浏览器页面竞争时仅一方成功，且均通过 SSE 收敛。拖动中发生外部修改时保留外部提交，旧手势拒绝覆盖。
- **显示与漫游**：进入、移动、转向、退出均真实执行；对象网格、材质与选择身份另有数据检查，不以截图代替。
- **交接与恢复**：完整停服数据目录复制后，项目身份、场景、历史位置和 GLB 字节一致；在恢复目录可继续重做。启动、配置、健康检查、工具、成员二/三接入说明齐全。

参数化配方的标称尺寸与完整网格包围尺寸分别记录在 `evidence/catalog-dimensions.json`。网格可能包含扶手、靠背或装饰物，不能把标称值直接当作精确网格尺寸。对照测试验证的是新旧网格一致性。

## 差异与边界

- 新版正式状态在项目服务；JSON 导出是当前快照和资产清单。恢复同一项目及完整历史使用项目服务或完整目录备份，导入 JSON 会新建项目。
- 渲染、相机和工作台由新模块管理。固定视角人工检查确认主体与位置一致；窗框、墙顶、门扇、背景及光照呈现有差异，不宣称像素级复刻。外部 GLB 的二维表示为包围矩形，三维使用真实网格与贴图。
- 原版尺寸过小的庭院门会形成负圆弧半径，新版在提交前拒绝宽度不大于 400 mm 的配方；行为修复独立提交。
- 首批 GLB 支持资源自包含、有三维体积的静态未压缩模型，PNG/JPEG 贴图。压缩扩展、骨骼动画、变形目标等明确返回不兼容原因。
- 检查工具复用参数化轮廓 SAT 与垂直区间、墙体及洞口检查。它不是精确网格、支撑面或通道可达性验证，返回值明确列出覆盖范围。
- S0 中原版独立分享 HTML 的隔离浏览器冷启动为**未验证**；新系统不交付该格式。S1 的保留核心流程没有以“未验证”结项。
- 多楼层、光追、全景、高级日照、报价、施工图、水电、智能家居演示属于**范围外**。目录中的相关家具仍保留。

当前交付是可用编辑器、项目服务与工具基础。S2 还需自然语言、户型图理解、四 Agent 编排、渲染取证与修复循环；S3 接真实照片生成服务；S5 才形成完整 AgentArts 平台体验。
