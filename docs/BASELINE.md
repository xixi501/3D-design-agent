## 固定样例

- `living-dining.spec.json` / `.plan.json`：HouseSpec、原版完整单层快照。
- `modeling-gallery.plan.json`：17 个造型家族及额外自由配方、柜体与常规家具。
- `glb-display.plan.json` + `textured-vase.glb`：含持久模型引用的展台；导入时将 `fixture-vase` 映射到上传返回的资产身份。
- `evidence/baseline/original-glb-project.json`：原版实际修改并保存的项目，含柜体、造型、结构修改和 GLB 实例。

重新生成参考入口后执行 `npm run test:baseline` 与 `npm run test:baseline:extended`。测试失败、目标缺失或渲染超时会使进程失败，不能以跳过记为通过。
