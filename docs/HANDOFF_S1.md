# 成员二、三接入说明

成员一交付的是单层编辑器、持久项目服务及真实场景工具。版本以本交付分支提交为准；启动与备份见 `RUNBOOK.md`，工具约定见 `API.md`。

## 成员二：GLB 入场

先用 `fixtures/textured-vase.glb` 验证链路，再替换为真实生成结果：

1. `POST /api/assets` 上传标准静态、未压缩且贴图完整嵌入的 GLB。
2. 读取返回的 w/d/h（mm）、归一化、SHA-256 和稳定 asset id。当前沿用原版尺度启发式，仍需用户确认生成物真实尺寸。
3. 读取项目 revision；提交 `add/furniture`，类型 `model`，保存 `modelId`、实例尺寸、x/y/z/rot。
4. 浏览器确认贴图、尺寸、位置；保存、关闭、重开，再撤销/重做。

`scripts/import-asset.mjs` 是可运行的完整示例。实例 z 表示底部离地；把花瓶放到 420 mm 高茶几上使用 z=420。服务只检查文件与场景基本一致性，S3 还需增加照片作业、尺寸确认、支撑面与落点检查、长任务失败恢复。

## 成员三：业务服务与平台工具

可提前把最小 AgentArts 应用连到 `/api/health`、`/api/catalog` 和某一测试项目的 GET/commands/checks。Python 通过 HTTP 调用即可，不另写一套几何与场景修改规则。

调用方为每个事务保存 operationId、baseRevision 和完整命令。相同请求重试复用身份；冲突时重新读取、重新推理，不能静默覆盖。SSE 可供浏览器显示进度，但任务编排、消息协议和平台作业恢复尚需 S2/S5 实现。

生产配置需固定 Node、依赖锁文件、业务 Git 提交以及持久数据目录。应用服务能访问资产 URL，浏览器能连接项目 API。部署过程不要把 `data/` 写进临时容器层；不需要携带原版参考 HTML 或 Python 复现环境来运行产品。
