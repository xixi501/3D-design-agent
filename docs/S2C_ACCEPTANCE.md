## 真实模型回归与开发失败

真实模型均为 DeepSeek 官方 API、`deepseek-flash`，提示词、工具、依赖版本、调用数、用量和耗时记录在每次任务轨迹中。当前提示词为 `s2a-local-edit-2`、`s2b-rectangular-2`、`s2c-floorplan-3`。固定 Skill 内容哈希见运行记录。

本轮首批旧流程回归在 `9285bb6` 运行：矩形文字四次中三次通过，阅读会客间第二次耗尽单次输出而缺失结构化结果；局部编辑六类中五类通过，删除请求漏报授权目标，被安全拦截且没有正式修改。已保留全部失败及成功记录。修复增加一次有预算的格式续答，并在主控结构化结果中校验删除权限；没有放宽检查或静默提交。

工具图片协议开发试验共五轮，原始记录全部保留：前两轮定位到 SDK 将工具图片序列化成文本；第三轮图片实际识别为“sofa 1”，严格无空格断言误判，随后只修正空白归一化；第四轮工具图片通过，但识别器猜测目录 key 导致拒绝；第五轮移除识别阶段的目录 key，图片及草稿协议通过。第五轮草稿仍有尺寸含义／缺失结构信息的不确定项，正确停在等待确认，没有自动猜测提交。

## 剩余验收与交接

1. 收到两张真实 PNG/JPEG 原图，登记 SHA-256、尺寸含义、房间与家具，冻结独立人工参考。
2. 每图运行两次，从原图识别开始，在工作台校正和确认；分别评分首次识别、累计人工校正与最终保真。阈值按批准计划保持不变。
3. 每张图成功保存后执行一次真实局部编辑，核对整层墙体、门窗及其他房间保护，再完成浏览器重启和持久历史复验。
4. 将图像矩阵与本报告的文字、局部编辑、故障及原能力结果合并复核，全部核心门槛通过后才标记完整 S2。
