## V3-5 根因

主因在固定图像候选层，不在三维生成：

1. `hpd-adapter-5` 没有沿实际凹形外墙建立候选，而是把图像/线条包围盒折叠成 `x≈91.5…649 / y≈76.5…549.2` 的矩形四面墙。
2. 结构骨架只留下北向内墙和一段卫生间墙，厨房、次卫、书房、卧室之间的多数内墙没有候选。
3. 原图有完整 `9700 / 8800` 及分段尺寸链，但 `dimensionCandidates` 为空，无法建立毫米比例和尺寸特征。
4. 厨房、卫生间固定设备、床和书桌轮廓进入可选对象集；连通客餐厅又被拆成两个目标标签，家具阶段生成了大量错误的 `chair` 候选。
5. DeepSeek 和三阶段自检已经把缺失墙、宽洞口和缺少标定记录为阻断，但没有候选证据就不能由代码凭提示词补出正确几何。
