## 已知限制与下一步优先级

- 单图背面是生成补全；当前案例证明背面材质仍需检查，不能只看正面或文件可打开。
- 当前为单进程单工作线程；长时间生成中查询可能短暂延迟，应使用带超时的 HTTP 客户端。
- 重启不自动续跑未完成任务；已完成结果可恢复。
- 首版不做真实尺寸推断，主系统必须让用户确认尺寸。
- 下一阶段优先处理背面材质与模型轻量化，再扩展固定案例数量。
