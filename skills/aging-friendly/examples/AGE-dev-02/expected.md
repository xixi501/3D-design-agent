# 预期结果

- `check.run`：**pass = false**；
- 必须出现：`CIR-02`（门洞 300mm 落脚带无自由格，门到房间主区不通）；
- 同时可能出现：`DOOR-02`（同一床体落在 900 门扇扫掠内）；
- 不应误报：`CUR-01`、`WIN-01`、`WALL-01`、`OVER-01`、`ASSET-02`。

# 说明

这个案例记录了一个引擎口径的事实：**450 的窄缝在 `CIR-02` 里仍被当作连通**（栅格 BFS 只要有一格自由就能穿过），
所以"床边只剩 450"不会自己触发通道告警；真正被抓到的是"床把门堵死"。
如果期望把 450 也拦下来，需要在判据层新增"最小净宽断言"，而不是靠这个案例凑。
