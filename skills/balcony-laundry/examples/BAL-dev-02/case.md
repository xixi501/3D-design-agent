# BAL-dev-02 · 洗衣机怼在推拉门后（边界／失败）

## 输入

- 同一个 1.6 × 3.2m 生活阳台（5.12㎡），北墙 1200 推拉门通客厅，西墙窗。
- 洗衣池与晾衣杆位置不变。

## 用户／错误做法

"机器放门口方便，一进门就能把衣服扔进去。"

洗衣机 600 × 600 中心 (450, 400)、烘干机 600 × 600 中心 (1075, 400)，两台并排贴北墙，占 x 150–1350、y 100–700——整个压在推拉门的 400 通行带里。

## 为什么必须拦

- 推拉门是阳台与客厅之间**唯一的通道**，门前 400 内被机器占满等于门只能开一条缝；
- 阳台被变成了"只能看不能用"的空间：拖把、晾衣、取放衣服都要侧身挤；
- 机器的背面贴门，门的轨道会被震动与潮气反复冲击，先坏；
- 排水也变远：机器在门口，立管在东南角，排水管要横穿整个阳台。

## 技能应如何反应

拒绝这个位置，按"排水 → 机器 → 晾晒 → 储物"的顺序重排：
1. 机器退回南墙、靠东南角立管，排水最短 [J-BAL-01]；
2. 门前 400 带（含地垫、门槛石）留空 [J-DOOR-01]；
3. 若南墙被窗或立管占住，改用**叠放**把占地压到一台，而不是把机器塞门口；
4. 两台都放不下时，只留一台 + 洗烘一体，如实报告，不要把通道当仓库。

## 判定

`check.run` 应报 `DOOR-01`（推拉门 sd1 前 400 内有洗衣机、烘干机）；技能不得把该方案标为已完成。
