# 预期结果

- `check.run`：**pass = false**；
- 必须出现：`DOOR-01`（"推拉门 sd1 前 400mm 内有 o_washer(washer)"），且烘干机同样被报。

# 说明

这个案例是**技能必须能识别并拒绝**的输入，也是阳台最常见的错：把"门边最方便"当成"最好的位置"。

- 正向案例里，同一扇推拉门、同一个阳台，机器放在南墙就干净；
- 边界案例里只把机器挪到门后，检查器立刻报错；
- 两个案例的窗、洗衣池、晾衣杆完全一样，差别只有机器的位置，归因清楚。

它同时说明为什么技能把顺序写成"排水 → 机器 → 晾晒 → 储物"：机器的位置由排水和门决定，不由"顺手"决定。

# 失效即表示

- 引擎没有把推拉门（`sliding`）计入 400 通行带，于是"门打不开"被漏判，或
- 洗衣机的深度/朝向被算错（门朝外开的那一侧才是操作面），导致实际占地与判定不一致。
