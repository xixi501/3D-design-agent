# 预期结果

- `check.run`：**pass = false**；
- 必须出现：`DOOR-02`（"门 d1 开启范围内有 o_toilet(toilet)"）。

# 说明

这个案例是**技能必须能识别并拒绝**的输入。它证明门扇扫掠区是真的参与几何判定，而不只是一条写在技能里的提醒：

- 正向案例里，同一扇门、同一个房间，马桶放在东墙就干净；
- 边界案例里，只把马桶挪进门扇扫掠区，检查器立刻报错。

两者的差别只有马桶的位置，所以报错一定归因于"门扇开启区"这一条，而不是别的检查串味。

# 失效即表示

- 引擎把门扇扫掠区按"门宽 × 门宽"以外的尺寸计算（口径被改），或
- 洁具被误判成"不阻挡地面"（例如把马桶当成挂墙件），于是"门打不开"这件事被漏判。
