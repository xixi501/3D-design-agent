# 预期结果

- `check.run`：**pass = false**；
- 必须出现：`DOOR-02`（"门 d1 开启范围内有 o_shoe(shoeCabinet)"）。

# 说明

这个案例是**技能必须能识别并拒绝**的输入，也是玄关最容易犯的错：把"顺手"当成"合理"。

- 正向案例里，鞋柜贴东墙，门扇扫掠区干净；
- 边界案例里，只把鞋柜横到门口，检查器立刻报错；
- 两个案例的房间、门、凳子、镜完全一样，差别只有鞋柜的位置，所以归因清楚。

它同时说明"保住顺序"为什么把门扇净宽排在第一位：鞋柜可以短、凳子可以收、镜可以贴柜门，**只有门扇开启后的净宽没有替代方案**。

# 失效即表示

- 引擎把门扇扫掠区算小了（例如按门宽 × 半门宽），或
- 鞋柜被误判成不阻挡地面（例如被当成挂墙件），于是"门打不开"这件事被漏判。
