# 预期结果

- `check.run`：**pass = false**。
- 必须出现：`CUR-01` —— 桌面（x 2200–2900 / y 600–2400，h=750）与东窗内侧 150 条带
  （x 2850–3000 / y 300–1500）相交，且 h > 600。
- 不应出现：`CIR-02`、`DOOR-02`、`OVER-01`、`WIN-01`、`ASSET-02`。
  （朝西的桌子仍在房间里、门弧内无家具、椅子与桌是允许贴靠的一类、书桌不属于柜类所以不触发 WIN-01、
  台灯完整落在桌面内。）

# 说明

这个案例演示的是"**尺寸对但位置错**"：
桌子本身是技能推荐的 1800 × 700，椅子、台灯都对，只有桌面被推到了窗帘带上。
如果引擎不报 `CUR-01`，说明"窗内侧 150"这条带子没接上，技能里写的"窗在侧向"就只剩文字。

同时必须承认：本案例**没有**验证 [J-LIGHT-05]（屏幕与窗的夹角）。引擎没有眩光判定，
这一条只能靠人评；交付里要写"背窗问题已提示，未实测"。

# 失效即表示

- 不报 `CUR-01`：窗帘带选错了窗（东墙 `win1`）或 h 阈值判错；
- 若报 `WIN-01`：说明 `desk` 被误归为柜类，要改引擎的分类表；
- 若报 `OVER-01`：说明桌与椅的例外（SEAT/TABLE）没生效。
