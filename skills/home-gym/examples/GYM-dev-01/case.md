# GYM-dev-01 · 13.6㎡ 健身角（正向）

## 输入

- 场景：矩形房间，轴线 3400 × 4000 mm，墙厚 200，内净约 13.6㎡（内净 3200 × 3800）。
- 洞口：
  - 北墙平开窗，宽 1200（距西端 300 → 1500），窗台高 900；
  - 西墙单开门，宽 900（距北端 2800 → 3700），向室内开。
- 用户原话："一台跑步机、一台动感单车，想铺开瑜伽垫，镜子要能照全身，别挡门。"

## 已知约束

- 净高 2700，无吊顶；跑步机站立面 1350，够 2.0m 人头。
- 保 700 连续通道；器械尾端（上下机那一头）朝南，后面留 1000。
- 镜子挂东墙实墙（1800 宽），正对房内空地；人站垫上能退开 2.5m 照到全身 [J-WALL-01]。
- 北墙那面有窗，不做镜面墙（窗内侧 150 留给窗帘）[J-CUR-01]。

## 判定

`check.run` 应无 error：
- 通道：从西门（西墙 2800–3700）→ 南侧空地 → 单车与跑步机之间 700 → 北侧窗下，全程 ≥700；
- 门扇 900 × 900 扫掠区内无落地家具；
- 镜子贴墙（≤180 容差内）且不压窗洞；
- 器械与柜体落地投影不重叠；窗内侧 150 无高件、窗前 400 无高柜。
