# 失效即表示

- 技能给的坐标本身违反判据（改案例或改技能）；
- 或引擎与判据口径不一致（改引擎，不能改期望来凑）；
- 或 `rug`/`yogaMat` 被当成障碍物参与通行与重叠判定——那说明引擎的"平铺件"口径错了，不是案例错。

> 说明：本案例的成组关系记录在 `source.activityGroups`（`name` + `memberIds`）里，是**元数据**。
> - 主系统不提供成组移动权限；
> - activityGroups 只用于识别、审核、证据与后续扩展；
> - 原始轮廓与对象所有权仍一对一。
