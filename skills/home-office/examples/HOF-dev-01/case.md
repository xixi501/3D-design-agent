# HOF-dev-01 · 9.5㎡ 书房 / 居家办公（正向）

## 输入

- 场景：矩形书房，轴线 3000 × 3600 mm，墙厚 200，内净约 9.5㎡。
- 洞口：
  - 北墙平开窗，宽 1600（距西端 700），窗台高 750；
  - 东墙单开门，宽 900（距北端 2600），向内开。
- 用户原话："每天视频会两三场，桌子要对着窗但不能顶到窗帘；白天不想开灯写东西；
  书房门在我右手边，摄像头别把走廊拍进去。"

## 已知约束

- 书桌 1200×600，桌前要能推椅、椅后要能起身；
- 书桌离窗墙留 300（给窗帘与暖气），但不能为此把桌子推到房间正中；
- 屏幕侧光：窗体在左前方，屏幕不正对窗、也不背窗；
- 视频背景要干净：椅子背后是一面墙 + 矮柜，不出现门、床、走道；
- 文件要能归档，不能全堆桌面。

## 技能给出的方案

| 对象 | 位置（中心，mm） | 朝向 | 说明 |
|---|---|---|---|
| 书桌 1200×600 | (1500, 750) | 0 | 桌前沿离窗墙内皮 350，破窗带且留窗帘位 |
| 办公椅 600×600 | (1500, 1350) | 180 | 椅背后 y 1650–2600 连续 950 |
| 书架 900×350 | (2725, 1200) | 90 | 东墙北段，随手取用，不压门 |
| 文件柜 450×550 | (325, 1200) | 0 | 西墙，存档，不在视频画面内 |
| 矮书柜 1200×300 | (1200, 3350) | 180 | 南墙，做视频背景 |
| 台灯 250×250 | (1950, 620) | 0 | `on` 书桌，压在桌面内 |
| 窗帘 2000×160 | (1500, 180) | 0 | 窗洞两侧各多 200，不碰桌 |

**三件取舍（本案例的核心判断）**：

| 取舍 | 选择 | 放弃的东西 | 为什么 |
|---|---|---|---|
| 桌对窗 vs 屏幕背光 | 桌与窗平行、人侧对窗 | 正对窗景 | 正对窗是背光，屏幕会变成剪影 [J-LIGHT-03] 的眩光问题 |
| 桌贴窗 vs 留 300 | 留 350 | 桌面进深方向的余地 | 窗帘要落地、暖气要散热，贴窗等于把这两件事都堵死 |
| 门在画面里 vs 背景干净 | 背景用南墙矮柜 | 门口动线的"顺路" | 视频背景一旦出现门和走道，会一直有人经过 |

## 判定

`check.run` 应无 error；再由人工复核：

- 椅后使用区：椅背 y 1650 → 门扇扫掠区起点 y 2600，连续 950 [J-CIR-05]；
- 桌前与窗墙内皮 350：不进窗内侧带 [J-CUR-01]，也给窗帘留了位置；
- 照度分层：顶灯 + 台灯 + 窗光三层，桌面 300–750 lux、色温白天与晚间分开 [J-LIGHT-02]、[J-LIGHT-03]；
- 造型克制：只有窗和书架两处视觉重音，桌面不做造型墙 [J-STY-03]。
