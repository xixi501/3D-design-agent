# KID-dev-02 · 9.5㎡ 儿童房（边界：第二张书桌塞进床尾）

## 输入

- 场景与 KID-dev-01 相同（3000 × 3600，北窗 1000，南门 900）。
- 现有：单人床 1200×2000（床头贴南墙）、衣柜 1000×600（西墙北段）。
- 用户原话："老二明年上小学，房间中间加一张 1 米的书桌和一把椅子，挤一点没关系。"

## 已知约束

- 房间内净 9.5㎡，床已占 2.0 × 1.2；
- 书桌 1000×600、椅子 460×520，家具尺寸不改；
- 不能动门窗、不能拆墙，也不能把孩子的东西扔出去；
- 家长接受"挤"，但不接受"没法用"。

## 技能给出的方案（错误示范，应被拒绝）

```json
{"op":"add","object":{"id":"o_desk2","key":"kidsDesk","at":[850,1750],"rot":90,"w":1000,"d":600}},
{"op":"add","object":{"id":"o_chair2","key":"chair","at":[1560,1750],"rot":270}},
{"op":"add","object":{"id":"o_mat","key":"playMat","at":[2100,2300],"rot":0,"w":1200,"d":900}}
```

书桌横放（rot 90）落在 (850, 1750)，实际占位 x 550–1150、y 1250–2250，
而床的实际占位是 x 100–1300、y 1400–3400——两者在 y 1400–2250 上压在一起。

## 判定

`check.run` 必须报 `OVER-01`，`pass = false`：落地家具重叠。

技能的正确反应不是"再挪 50 试试"，而是先承认这个房间放不下第二张 1 米书桌，
然后给三条可以落地的替代（见 SKILL.md 第 4 步）：

1. 书桌与衣柜共用西墙，改为 800 宽窄桌 + 墙上折叠桌板（高度不够时用可调桌腿）；
2. 换成上下床（1000×2000），把床的占地从 1.2m 宽压到 1.0m，书桌沿东墙布置；
3. 只在小学低年级用"餐桌 + 可移动书桌"的过渡方案，学龄期再整体换布局。

同时把"挤"的后果写清楚：桌前使用区不足会直接影响 [J-CIR-05]，
这在同一间房里是先于美观的硬约束。
