# KIT-dev-02 · 2.1m 开间硬做双排（边界／失败）

## 输入

- 场景：矩形厨房，轴线 2100 × 3100 mm，墙厚 200，内净约 5.9㎡（轴线面积 6.51㎡）。
- 洞口：南墙单开门，宽 700（距西端 700），向室内开；无窗（暗厨房，靠排烟与门洞换气）。
- 用户原话："两边都做柜子，台面越多越好，反正我一个人用。"

## 错误做法

东西两侧各做一条 600 深的通长地柜：

- 西墙柜 x 100–700，y 100–2900；
- 东墙柜 x 1400–2000，y 100–2900；
- 中间只剩 x 700–1400，即 **净通道 700**。

## 为什么必须拦

开间 2100，扣掉两排柜各 600 后只剩 900 的"毛"空间，再扣墙面粉刷与柜门缝，实际净通道 700。按选形表，2100 属于"一字"档，双排会落到 [J-KIT-02] 的下限以下；而 700 只是 [J-CIR-01] 的应急值，不能当厨房的操作通道。这个厨房里两人无法错身，洗碗机门与烤箱门打开时也站不下人。

## 技能应如何反应

拒绝双排，并给替代：
1. 退回一字形（单排 600 + 净通道 1300），把水槽与灶台排在同一条台面上；
2. 或保留双排但把东侧改成 350 深的浅柜/折叠台面，净通道升到 1000；
3. 说明原因：开间 2100 < 双排所需，通道不足；不是"柜子不够多"，是开间不够。

## 判定

`check.run` 应报 `CIR-02`（房间内没有 ≥ 900 的通行区）；技能不得把该方案标为已完成。
