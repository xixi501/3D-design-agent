# 预期结果

- `check.run`：**pass = false**；
- 必须出现：`CIR-02`（"房间 厨房 内没有 ≥900mm 的通行区"）——对应判定 [J-CIR-01] 的口径，也是 [J-KIT-02] 被违反后的几何后果。

# 说明

这个案例不是"技能做错了"，而是**技能必须能识别并拒绝**的输入。它证明两件事：

1. 选形表不是文案：开间 2100 做双排，几何上真的会掉到 900 以下；
2. 检查器确实会拦——如果引擎在这里不报 `CIR-02`，技能里写的"双排要够开间"就没有执行依据。

# 失效即表示

- 引擎把 700 的通道算成了合格通道（阈值口径被改宽），或
- 双排案例里柜体没有真正进入通行计算（重叠豁免被误用）。
