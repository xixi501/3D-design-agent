# 照明分层与配色

## 什么时候用

✅ 适用：
- 平面布局已定（沙发、餐桌、床都摆好了），要补"灯在哪、多亮、什么色温"；
- 用户抱怨"家里暗 / 只有一盏顶灯 / 晚上开灯刺眼 / 颜色显脏"；
- 要出材料与颜色的采购口径（墙面、柜面、布艺各选什么）。

❌ 不适用（转其他技能或交回主控）：
- 需要电气施工图（回路划分、线径、开关点位、双控走线）：超出本技能，交回主控；
- 家具位置还没定：先跑对应的场景技能，再回来补灯；
- 需要智能家居协议/品牌选型：只给"可调光 + 可调色温"的能力要求，不选型。

开工前只问三件事，问不到按保守值：
1. 层高多少（决定吊灯下沿与灯距；未知按 2700）；
2. 主要活动时段（白天在家多还是晚上多，决定色温默认值）；
3. 有没有必须保留的灯位或线路（有则灯位围绕它排，不重开槽）。

## 怎么做

本技能只提供约束与验收项，不独立产生第二轮修改。

**第 1 步 · 先定三层比例，再挑灯**
- 环境层 60–70%：顶部基础照明，负责"不黑"；
- 任务层 2–3 倍环境：餐桌、书桌、灶台、镜前，负责"看得清"；
- 重点层 3–5 倍环境：挂画、柜内、绿植，负责"有层次"；
- 只有一盏顶灯 = 没做分层，直接判不合格 [J-LIGHT-01]。

落地写法：一个房间至少 3 个回路（环境 / 任务 / 重点），每个回路可独立开关。

| 层 | 占环境照度 | 常见灯具 | 控制方式 |
|---|---|---|---|
| 环境 | 60–70% | 筒灯、面板灯、灯带 | 一个开关，可调光 |
| 任务 | 2–3 倍 | 餐桌吊灯、台灯、橱柜灯带、镜前灯 | 分区开关 |
| 重点 | 3–5 倍 | 射灯、壁灯、柜内灯 | 单独回路，可常亮 |

**第 2 步 · 按房间给照度**

| 场景 | 一般照度 | 任务面照度 | 备注 |
|---|---|---|---|
| 客厅 | 150–300 lux | 阅读位 300–500 | 阅读位按"书本面"算，不是地面 |
| 餐厅 | 150–300 lux | 餐桌桌面 300–500 | 吊灯距桌面 700–800 |
| 厨房 | 200–300 lux | 台面 300–750 | 吊柜下补灯带，人站的位置不投影 |
| 卧室 | 50–150 lux | 床头阅读 300 | 顶灯不装在床正上方 |
| 卫浴 | 100–200 lux | 镜前 300–500（垂直） | 垂直照面，不是顶光照脸 |

数值口径见 [J-LIGHT-02]；照明设计值以实测或厂家光度报告为准，本表用于方案阶段定位。

**第 3 步 · 色温**
- 白天活动区 4000–5000K；晚间起居 2700–3000K；夜间起夜 ≤ 2700K [J-LIGHT-03]；
- 卧室主灯避免 > 4000K；同一视野内色温差不超过 1000K，否则显脏；
- 一个房间允许"主灯 3000K + 重点 2700K"，不允许"主灯 4000K + 重点 2700K"混在同一视线里。

| 时段 / 场景 | 色温 | 说明 |
|---|---|---|
| 白天活动区 | 4000–5000K | 与自然光接近，不显脏 |
| 晚间起居 | 2700–3000K | 暖光收敛，显材质 |
| 卧室、起夜 | ≤ 2700K | 不打断褪黑素 |

**第 4 步 · 均匀度**
最大照度 : 最小照度 < 3 : 1，不留暗角 [J-LIGHT-04]。
做法：灯距 ≤ 1.2 × 灯具安装高度；边角补一盏小功率；不要用一盏大灯硬照整个房间。

**第 5 步 · 灯位必须落到家具上（本技能最容易被跳过的一步）**
- 餐桌吊灯：灯中心对餐桌几何中心，偏差 ≤ 100；灯罩下沿距桌面 700–800；
- 阅读角：落地灯放在椅子侧后方 200–400，灯罩下沿低于坐姿视线（约 1100–1200）；
- 镜前灯：装在镜子两侧或上方 150–200，光垂直照面，不装在头顶；
- 吸顶件（吊灯、风扇灯）只按"天花板坐标"落位，不参与贴墙判定；
  落地件（落地灯）按地面坐标落位；台面件（台灯）必须用 `on` 挂到具体台面上 [J-ASSET-02]；
- 挂墙件（壁灯、挂画）必须落在实墙、避开洞口 [J-WALL-01]。

**第 6 步 · 自然光与窗帘**
- 先算自然光：窗地比不足时，白天也要开环境灯；
- 窗帘盖住整个窗洞、两侧各多 100–200；窗帘前 150 内不放高于 600 的落地家具 [J-CUR-01]；
- 窗帘选"纱 + 布"双层：白天用纱，晚间用布，避免白天拉布导致全屋发灰。

**第 7 步 · 配色落地到材质**
- 60-30-10：主色 60%（墙、大件家具）、辅色 30%（窗帘、地毯、柜门）、点缀 10%（抱枕、挂画、单椅）[J-COL-01]；
- 同一空间主材 ≤ 3 种 + 1 种点缀 [J-COL-02]；
- 颜色必须写成"可采购的描述"：不是"高级灰"，而是"墙面 NCS S1500-N、柜面哑光暖白、沙发浅灰棉麻"；
- 灯光会改色：3000K 下蓝色会发灰、红色会发橘，**先定色温再定颜色**。

**第 8 步 · 交付约束与验收项（不自己提交）**

1. 把本步确定的约束整理成"编辑约束 + 验收清单"（尺寸、位置、材料、检查项），随交付交给主设计；
2. 只改指定对象，无关家具与户型不动 [J-VER-01]；候选的提交与预检由主 Skill 和固定代码执行，本技能只声明"什么算合格"；
3. 修复轮次沿用主系统现有预算 [J-VER-02]；本技能不新增轮次，也不替主系统宣布通过。
4. 只改指定对象、无关家具与户型不动 [J-VER-01]；修复沿用主系统现有三轮预算 [J-VER-02]，本技能不新增轮次，也不替主系统宣布通过。

## 依赖什么

本技能只使用以下语义能力（不含任何写场景权限）：

| capability | 用途 |
|---|---|
| `scene.read` | 读取当前场景/现状 |
| `catalog.search` | 检索家具库，取默认尺寸与挂墙属性 |
| `candidate.review` | 复核候选与需求、判据的一致性 |

**边界**：本技能不提交候选、不跑预检，只向主设计注入约束与检查项；提交与预检由主 Skill 和固定代码执行。
**降级路径**：约束以清单形式交付（尺寸/位置/材料/检查项），由主系统转成编辑，不声称已执行。

## 怎么验证

- **正向** `LGT-dev-01`：4.2 × 5.4m 客餐厅，北窗 2400、西墙门；餐桌 1400 × 800 上方 `chandelier` 对中，东南阅读角 `armchair` + `floorLamp`，南墙 `wallArt` 作重点。期望 预检 全通过。
- **边界** `LGT-dev-02`：为了"进门就有光"，把落地灯放到西墙门边、正落在 900 门扇的开启范围里。期望报 `DOOR-02`；技能应改灯位（挪到门侧 400 外或改用壁灯），不是把门改小。
- **反向校验**：把 `LGT-dev-01` 的吊灯平移到偏离餐桌中心 400，预检 不会报错——说明"对中"只能人评/半自动，**不能假装自动**。

两个案例在 `examples/` 下，`ops.json` 可被 `tools/dry_run.py` 复跑；L1 结构与 L2 几何结果记录在 `manifest.validation`。
