# LDO-dev-01 · 50㎡ LDK 一体厅（正向）

## 输入

- 场景：矩形 LDK 一体厅，轴线 6000 × 8400 mm，墙厚 200，内净约 47.6㎡。
- 洞口：
  - 北墙入户门，宽 900（距西端 4200），向内开；
  - 南墙落地窗，宽 3600（距西端 1600），窗台高 400。
- 用户原话："一家四口，要一个能做饭、吃饭、会客的大厅；不要一进门就看见沙发背面；孩子得有地方跑。"

## 已知约束

- 三段分区且不砌墙：北侧西厨（台面 + 冰箱）、中北用餐（长桌四椅）、南侧会客；
- 分区靠电视矮柜做"半岛"，半岛两端都要能过人；
- 只留落地窗这一个视觉焦点，其余造型压低；
- 全屋走同一风格，硬装不动。

## 判定

`check.run` 应无 error：分区半岛两端通道、餐区进出、窗内侧净空、门扇开启、重叠、挂墙全部通过。

分区半岛两端实留：沙发东端到东墙内皮 2100；沙发西端到西墙内皮 1500；矮柜东端到东墙内皮 2200；
矮柜背面到餐桌前沿 1600。会客区没有贴满墙，南窗前也没有高于 600 的落地家具。
