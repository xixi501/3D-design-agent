# LDO-dev-02 · 50㎡ LDK 一体厅（边界：分区做满，动线被切断）

## 输入

- 房间、洞口、面积与 LDO-dev-01 完全相同（6000 × 8400，南窗 3600，北门 900）。
- 用户原话："分区要明确，别一进门就看穿整个大厅。"
- 设计师的理解：把"分区"做成一条从西墙连到东墙的矮柜带——中岛 + 台面 + 餐边柜三段首尾相接。

## 已知约束

- 入户门在北墙东段（x 4200–5100），进来先到的是餐区；
- 会客组在南侧，唯一的自然光在南窗；
- 用户明确要求"分区要明确"，但没说可以让某一区走不到。

## 技能给出的方案（错误示范）

| 对象 | 位置（中心，mm） | 实际范围 | 用途 |
|---|---|---|---|
| 中岛 1800×900 | (1000, 2800) | x 100–1900 | 分区带西段 |
| 台面 2100×600 | (2950, 2800) | x 1900–4000 | 分区带中段 |
| 餐边柜 1900×400 | (4950, 2800) | x 4000–5900 | 分区带东段，顶到东墙 |

三段首尾相接、两端顶到墙内皮，全厅 6000 的宽度上没有任何断点。

## 判定

`check.run` 必须报 `CIR-02`：从入户门出发只能到达 17% 的通行区域——南侧的会客组（沙发、茶几、地毯）
被这条柜带彻底隔开，进门后走不到落地窗前。`pass = false`。

这是"分区"与"动线"冲突时应该被拦住的典型做法。正确做法见 LDO-dev-01：半岛两端各留一条通长通道。
