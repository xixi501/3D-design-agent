# MBR-dev-01 · 15㎡ 主卧（正向）

## 输入

- 场景：矩形主卧，轴线 3600 × 4200 mm，墙厚 200，内净约 13.6㎡（轴线 15.1㎡）。
- 洞口：
  - 东墙平开窗，宽 1200（距北端 1400），窗台高 600；
  - 南墙单开门，宽 900（距西端 2200），向室内开。
- 用户原话："要 1.8 米的大床、两口人分开的床头柜、一个大衣柜；梳妆台想要，但更想要衣柜。
  不装电视了，卧室不看。"

## 已知约束

- 床必须 1800×2100，且床头不能对着门；
- 衣柜平开门，柜前要能站人开门；梳妆台与衣柜二选一；
- 窗在东墙，窗帘要能落地；床不能压到窗内侧带；
- 承重墙不动，水电点位不改。

## 技能给出的方案

**床头墙 = 北墙**：3600 长、无洞口、不正对南门；进门先看到床尾与衣柜侧面，不直视床头。

| 对象 | 位置（中心，mm） | 朝向 | 说明 |
|---|---|---|---|
| 双人床 1800×2100 | (1650, 1150) | 0 | 床头贴北墙，床尾朝南 |
| 床头柜 500×420 | (450, 540) | 0 | 床西侧，离床 50 |
| 床头柜 500×420 | (2850, 540) | 0 | 床东侧，离床 50 |
| 床尾凳 1400×400 | (1650, 2400) | 0 | 贴床尾，可当换衣座 |
| 衣柜 2000×600 | (1100, 3700) | 0 | 南墙西段，平开门朝北 |
| 窗帘 1600×160 | (3420, 2000) | 90 | 窗洞两侧各多 200 |
| 床头挂画 900×40 | (1650, 100) | 0 | 挂北墙，避开洞口 |
| 台灯 250×250 | (450, 540) | 0 | `on` 床头柜，压在柜面内 |

**取舍（本案例的核心判断）**：3.4m 内宽上放不下"床 1.8 + 衣柜 0.6 + 梳妆台 0.45"三件并排，
梳妆台让位给衣柜；梳妆改成衣柜内侧抽拉镜 + 床头一盏可移动镜前灯。
电视同样让位：床尾正面是衣柜，不挂电视，改挂画作焦点 [J-STY-03]。

## 判定

`check.run` 应无 error；再由人工复核三条引擎不判的项：

- 床两侧通道：西 650、东 950，双人床两侧不同宽但都够起身 [J-CIR-04]；
- 衣柜前净空：床尾凳外沿 2600 → 衣柜前沿 3400，共 800，够平开门 [J-CIR-06]；
- 床没进窗内侧带（床在 y 100–2200，窗带在 x 3350–3500 一侧）[J-CUR-01]；
- 房间面积满足下限 [J-STA-01]；主家具不超所在墙 2/3 [J-PROP-01]（衣柜 2000 / 3600 ≈ 0.56）。
