# 影音 / 娱乐室

## 什么时候用

✅ 适用：
- 独立影音室、家庭影院、游戏室、看球房，使用面积约 10–25㎡；
- 用户要"投大屏/上大电视、能坐三五个人、白天也能看"；
- 已有一版含墙体与门窗的场景，或户型图已解析成场景。

❌ 不适用（转其他技能）：
- 客厅兼影院：转 `living-dining-small` 或 `living-dining-open`（主墙同时也是会客墙，取舍不同）；
- 需要声学装修（吸音棉、隔声门、浮筑地板）：超出本技能，交回主控；
- 投影吊装、强弱电点位、音响线预埋：平面解决不了，标出来交电工；
- 需要拆墙、改门窗：超出本技能。

开工前问四件事（问不到就按保守值）：
1. 主要看什么（电影/球赛/游戏）——游戏要更近、电影要更远；问不到按电影做；
2. 常坐几个人——决定沙发是 2.6m 一字还是加第二排；问不到按三人做；
3. 白天用不用——决定遮光等级与窗帘做法；问不到按"白天也用"做双层帘；
4. 有没有投影/功放/低音炮——决定设备柜尺寸与散热位置；问不到按有源音箱 + 单个设备柜做。

## 怎么做

**第 1 步 · 先定屏幕，再定沙发（本技能的核心判断）**
观看距离按 [J-VIEW-02] 的"屏幕对角线 × 1.2–1.6"估算舒适区（判据库条目，半自动：需屏幕尺寸与座位坐标；dry-run 引擎不检查）：
`catalog.search` 取幕布/电视的宽高，算对角线，乘 1.2 与 1.6 得到"最近—最远"两档；沙发前沿落在这个区间里。算一遍正向案例的账：

- 幕布 2400 宽、16:9 → 高 1350，对角线 ≈ 2.75m；
- 最近 2.75 × 1.2 ≈ 3.3m，最远 2.75 × 1.6 ≈ 4.4m；
- 房间净深 4.8m，沙发靠后墙时前沿约 3.8m → 落在区间内，不再调整。

算出区间后，按两种情况落位：

- 房间净深不够：**缩屏幕，不要缩通道**——屏幕小了还能看，通道窄了每天难受；
- 房间太深：不要用更大的屏，改用"沙发前移 + 后墙做储物/展示"，把后区留成走动与游戏空间。

**第 2 步 · 屏幕墙与视线高度**
- 屏幕墙选**最长、无洞口**的一面实墙；墙上有窗、有门都不行（漏光、动线穿屏）；
- 屏幕墙不要与窗正对：显示面法线与主采光窗法线的夹角要 ≥ 90°，窗在侧向最好 [J-LIGHT-05]；窗在屏幕背后（逆光）或正对屏幕（反光）都要改；
- 屏幕中心不高于坐姿视线，仰头看两小时会累；投影幕的下沿要避开沙发靠背遮挡；
- 屏幕/电视柜沿墙长度不超过该墙面长的 2/3 [J-PROP-01]，超了会把整面墙压死。

**第 3 步 · 沙发排布与侧向通道**
- 主沙发正对屏幕、靠后墙留一条检修/绕行缝（不要完全贴死，后墙要过线）；
- 沙发两侧各留 ≥ 700 的侧向通道 [J-CIR-01]；能做到 900 更稳，因为进出场要端饮料、抱小孩；
- 沙发不要为了"居中"顶到侧墙：两侧不对称时，宁可沙发偏，也让两侧通道都成立；
- 沙发到茶几按 400–500 的口径留 [J-CIR-07]，茶几选矮、窄、圆角。

**第 4 步 · 多人观看**
- 第二排抬高一层踏步，或用错位（后排比前排偏半个座位）让视线越过前排靠背；
- 第二排的踏步本身占深度，要从通道里扣；踏步不要压在门扇开启弧线里；
- 超过五人的场合，本技能只排"主排 + 一条踏步"，其余交 `living-dining-open` 做多功能分区。

**第 5 步 · 音箱位与墙角**
- 前置左右箱在屏幕两侧、离侧墙留缝，不要贴死墙角（低频会浑）；
- 低音炮可以靠近墙角，但**不要塞进沙发与墙之间的缝**——塞进去就是与沙发投影相撞 [J-OVER-01]；
- 环绕箱在座位侧后方，落地箱要算进通道账（它是落地家具，不是软装）；
- 吸顶音箱按吸顶件处理，不占地面，但要避开吊顶造型与灯位。

**第 6 步 · 遮光与吸音**
- 窗帘盖满整个窗洞、两侧各多 100–200；窗内侧 150 内不放高于 600 的落地家具 [J-CUR-01]；
- 白天要看的房间，窗帘做双层（遮光 + 纱），遮光层不落地就挡不住地脚漏光；
- 地毯是最便宜的吸音手段：铺在主沙发与屏幕之间，至少压住沙发前腿；
- 吸音板、软包属于声学装修，不在本技能的平面范围内。

**第 7 步 · 设备柜与检修**
- 功放、播放器、游戏机集中在设备柜：柜背留通风，不做死背板；层板留缝；
- 柜子可开启、可拉出，强弱电箱与水表不得封死在柜内 [J-ENT-03]；
- 设备柜如果做到 2.4m 高，必须能固定于实墙（高柜倾倒风险），并且不挡窗 [J-WIN-01]；
- 屏幕墙一侧留一个可开的检修口，换线时不用拆柜。

**第 8 步 · 照明**
- 分三层：环境（洗墙/灯带）+ 任务（座位侧阅读）+ 重点（屏幕背后或幕布上方）[J-LIGHT-01]；
- 观影时不要有灯直射屏幕或直射眼睛：灯具避开屏幕反射角，做可调光；
- 屏幕正上方不要装筒灯（会在幕布上打出光斑）。

**第 9 步 · 提交与检查**
1. 先提交幕布/电视与设备柜，`candidate.preflight` 看挂墙与遮挡 [J-CIR-02]；
2. 再提交沙发与茶几，看两侧通道与重叠；
3. 最后提交音箱、地毯、窗帘；
4. 最多 3 轮修复 [J-VER-02]；仍不通过的项写进"未解决清单"，说明是"放不下"还是"取舍没定"；
5. 只改本次涉及的对象 [J-VER-01]。

**第 10 步 · 常见错误与对策**

| 现象 | 原因 | 对策 |
|---|---|---|
| 看久了累/头晕 | 沙发太近，超出对角线 × 1.2 | 沙发后移或缩屏幕 |
| 画面"不够大" | 沙发太远，超出对角线 × 1.6 | 沙发前移，不要盲目换大屏 |
| 侧向走不过人 | 沙发为了居中顶到侧墙 | 沙发偏向一侧，两侧各保 700 [J-CIR-01] |
| 白天发灰 | 窗帘没盖满、地脚漏光 | 双层帘、盖满窗洞、帘长落地 |
| 设备柜发烫 | 背板封死、层板贴死 | 留通风与可开检修口 [J-ENT-03] |
| 低音炮发嗡 | 塞进沙发与墙的缝 | 离墙留缝、别与沙发投影相交 [J-OVER-01] |
| 屏幕上有光斑 | 屏幕正上方装了筒灯 | 灯位移到幕布侧上方，做可调光 |
| 换个屏幕就"不够沉浸" | 只换屏、没改座位距离 | 先按对角线 × 1.2–1.6 重算沙发位 |

## 依赖什么

本技能只使用以下语义能力（不含任何写场景权限）：

| capability | 用途 |
|---|---|
| `scene.read` | 读取当前场景/现状 |
| `catalog.search` | 检索家具库，取默认尺寸与挂墙属性 |
| `candidate.propose` | 产出候选（主系统审批后落库） |
| `candidate.preflight` | 几何与净空预检，返回问题码 |
| `candidate.review` | 复核候选与需求、判据的一致性 |

**边界**：不持有写权限——没有场景写入能力，也没有项目提交能力。技能只产出候选与验收意见，正式场景由主系统审批、落库与回滚。
**降级路径**：上述 capability 未接入时，输出坐标方案（mm，`at` 为家具中心）+ 验收清单，交主系统转成场景；不得声称已执行。

## 怎么验证

- **正向** `MED-dev-01`：4.2 × 5.0m 影音室（内净约 4.0 × 4.8m）。北墙 2400 宽投影幕、南侧 2.6m 影院沙发、沙发前沿到幕布约 3.8m（幕布对角线 2.75m × 1.4，落在 1.2–1.6 区间）、两侧各 700 通道、西墙设备柜、东墙窗 1800 宽配整体窗帘、墙角低音炮。期望 `candidate.preflight` 全通过。
- **边界** `MED-dev-02`：把 2.4m 高的设备柜挪到东窗前（"走线方便"）。期望报 `CUR-01`（窗帘活动区）与 `WIN-01`（高柜挡窗），技能应改为设备柜贴西墙或南墙无窗段。

两个案例在 `examples/` 下，`ops.json` 可被 `tools/dry_run.py` 复跑；L1 结构与 L2 几何结果记录在 `manifest.validation`。
