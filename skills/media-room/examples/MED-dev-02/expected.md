# 预期结果

- `check.run`：**pass = false**；
- 必须出现：`CUR-01`（窗内侧 150 内有 h > 600 的落地家具：2.4m 设备柜）、`WIN-01`（窗台 700 高、窗前 400 内出现 2.4m 的柜体）；
- 不应出现：`OVER-01`（设备柜与沙发/茶几不相交）、`DOOR-02`（柜子不在西墙门扇区）、`ASSET-02`（本案例没有台面物件）。

# 说明

这个案例不是"技能做错了"，而是**技能必须能识别并拒绝**的输入。它证明：
1. "走线方便"是真实的选位动机，但遮光与开窗是硬约束，检查器会拦；
2. `CUR-01` 与 `WIN-01` 各管一段：前者管窗帘能不能动，后者管窗能不能用——两条同时报，说明这个位置是"双重不可用"，不是换个柜型就能救。
