# NUR-dev-02 · 把婴儿床推到东窗下（边界／失败）

## 输入

同一个 3000 × 3600 婴儿房，东墙窗 900（窗台 900），南墙门 900（距西端 200）。

## 用户／错误做法

"床放窗边吧，通风好、还能看院子；白天窗帘一拉也不晒，正好。"

## 技能应如何拒绝

1. **床占住窗帘活动区**：床（1250 × 700，h=950）贴到东墙，床面高过窗台，窗帘落不下来 [J-CUR-01]；
   引擎会直接拦这一条。
2. **窗边是冷桥与风口**：外墙窗侧冬天玻璃面温度低、风口直吹床面，婴儿不会自己翻身躲开——
   这条判据库没有专项 ID，属安全常识，交付里要写明。
3. **双通道被吃掉**：床贴东墙只剩西侧一条通道，夜里从另一侧探视、换床单都要跨床 [J-CIR-04] 的"两侧都要能走"不成立。
4. 替代方案（按优先序）：
   - 床回到北墙（现状 NUR-dev-01），床头靠实墙、两侧都留 600+；
   - 或床留北墙但整体西移，东侧让给尿布台与窗；
   - 若房间实在只有一面可用墙，也宁可把床放**内墙**一侧（非外墙、非窗），不要放窗下。

顺带说清"床不放窗下"的三个理由：窗帘与风口、外墙冷桥、以及夜里拉帘/开窗都要越过床，
等于把"通风"和"安全"做成二选一。

## 判定

`check.run` 应 `pass = false`：报 `CUR-01`（窗内侧 150 内有 h>600 的落地家具 `o_crib`）。
门扇、重叠、支撑、柜体挡窗都应仍然通过——本案例只演示"床压窗"这一个错，
双通道不足（[J-CIR-04]）引擎不查，靠人工在 expected 里写明。
