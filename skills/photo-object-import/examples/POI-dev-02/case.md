# POI-dev-02 · 尺寸没确认就硬放（边界／失败）

## 输入

同 `POI-dev-01` 的场景与茶几。

## 用户／错误做法

用户说不清花瓶多大，只回了一句"比一般的花瓶大一点"，技能如果直接按模型估的包围盒（700 × 700）往茶几上放，就会出现 700 深的物体落在 600 深的台面上。

## 技能应如何反应

1. 在落位前停在"尺寸确认"这一步：给参照物（A4 纸 297×210、常见花瓶口径）或给 25/35/45cm 三档让用户选；
2. 用户坚持用 700 × 700 时，**改落点**：放地面（落地花瓶）或换更大的台面（电视柜/餐桌）；
3. 明确说明"尺寸未确认，超出支撑面"，不要把失败写成完成。

## 判定

`check.run` 应报 `ASSET-02`（资产超出支撑物范围），技能不得把这次落位标为成功。
