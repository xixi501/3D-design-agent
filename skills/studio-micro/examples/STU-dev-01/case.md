# STU-dev-01 · 28㎡ 开间（正向）

## 输入

- 场景：矩形开间，轴线 4000 × 7000 mm，墙厚 200，净约 25.8㎡。
- 洞口：
  - 北墙入户门，宽 900（距西墙 400），内开；
  - 东墙平开窗，宽 1600（距北墙 3600），窗台高 900。
- 用户原话："一个人住，偶尔两个人；要在家办公两天，朋友来要能坐下吃饭；不想砌墙，但睡觉不想被看见。"

## 已知约束

- 床与衣柜不可折叠，先占两端；桌子一张，工作与用餐共用；
- 书架（900×350）垂直摆在中段做软隔断，不砌墙；
- 保 700 连续通道；床不横在门与主区之间。

## 技能给出的方案

- 睡眠端（南）：1500×2050 床贴南墙、床头朝南，床头柜在床侧；
- 收纳端（西北）：1000×600 衣柜贴西墙，避开入户门扇；
- 会客组（西中段）：2200 沙发贴西墙、1200×600 茶几距沙发前沿 450，2000×1700 地毯；
- 工作/用餐（东北）：1200×800 桌 + 2 餐椅 + 1 办公椅，桌上吊灯；
- 软隔断：900×350 书架垂直摆在会客与睡眠之间，两侧各留 ≥700；
- 东窗 2400 落地帘，窗帘带内不放高家具。

## 判定

`check.run` 应无 error（700 通道连续、门扇开启区净空、窗帘带净空、无重叠）。
