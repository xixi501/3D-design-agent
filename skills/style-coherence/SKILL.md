# 全屋风格统一

## 什么时候用

✅ 适用：
- 用户说了风格词（现代简约 / 北欧 / 新中式 / 轻奢 / 日式原木 / 美式 / 工业 / 奶油 / 侘寂），但没给具体家具；
- 已有硬装（门、地板、墙色）不能动，要在其上选软装；
- 方案做完了要自检："是不是三种风格拼在一起""是不是网红堆砌"。

❌ 不适用（转其他技能或交回主控）：
- 只调家具位置、不加风格判断：直接用对应场景技能；
- 需要拆改硬装（换门、换地板、改墙色）：超出本技能，交回主控并说明原因；
- 需要品牌、价格、采购清单：本技能只给材质与颜色，不做选品比价。

开工前只问三件事，问不到按保守值：
1. 硬装三件（门、地板、墙色）现在是什么（木色深浅 / 冷白还是暖白）？——这决定能选哪些风格；
2. 住几口人、有没有小孩宠物（决定耐脏与耐磨的优先级）；
3. 有没有一件"必须留下"的家具（有则它以它为主色）。

## 怎么做

本技能只提供约束与验收项，不独立产生第二轮修改。

**第 1 步 · 先读硬装，再谈风格**
`scene.read` 取已有对象的材质与颜色（门、地板、墙色、已固定的柜体）。
硬装是三件"不可谈判项"，风格只能服从它 [J-STY-02]。判断口径：

| 硬装 | 能配 | 不要配 |
|---|---|---|
| 深红木地板 + 深色门 | 新中式、美式、侘寂 | 奶油、日式原木、极简白 |
| 浅橡木地板 + 白门 | 北欧、日式原木、现代简约、奶油 | 工业、轻奢（除非换软装压色） |
| 灰色地砖 + 黑框门 | 现代简约、工业、轻奢 | 奶油、侘寂（灰底压不住暖调） |

**第 2 步 · 写一张"风格卡"（四件套，一行写完）**
不写形容词，只写可核对的四项：**硬装基调 / 主材 / 五金与线条 / 软装关键词**。

| 风格 | 主材（≤3） | 五金与线条 | 软装关键词 | 常见翻车 |
|---|---|---|---|---|
| 现代简约 | 哑光白墙、浅木、岩板 | 窄边框、无把手、黑/砂银 | 直线、留白、藏光 | 线条太多变成"精装房" |
| 北欧 | 白墙、浅橡木、棉麻 | 细黑金属、圆角 | 浅色、绿植、羊毛 | 冷白 + 灰蓝堆成"样板间" |
| 新中式 | 深木、宣纸白、黄铜 | 回纹、格栅、铜色 | 对称、留白、青瓷 | 红木家具 + 现代沙发混摆 |
| 轻奢 | 大理石纹、金属、丝绒 | 香槟金、细框 | 反光、深色、单椅跳色 | 金色面积过大 |
| 日式原木 | 浅木、白墙、藤编 | 原木色、无漆 | 低矮、亚麻、纸灯 | 木色超过三种深浅 |
| 美式 | 深木、护墙板、布艺 | 做旧铜、宽线条 | 厚实、对称、地毯 | 碎花 + 深色同时上 |
| 工业 | 水泥、黑铁、原木 | 黑铁、外露管线 | 裸露、皮质、砖 | 冷灰配暖木比例失衡 |
| 奶油 | 奶白、微水泥、圆角 | 哑光白、无把手 | 圆弧、羊羔绒、暖光 | 全屋一个米色没有层次 |
| 侘寂 | 微水泥、原木、亚麻 | 无、留手工痕 | 素色、单枝、粗陶 | 做得太"精致"反而失真 |

选定之后，同一空间的所有家具（沙发、茶几、单椅、柜体、灯具）都按这张卡选，**不允许一件一个风格** [J-STY-01]；
拿不准的款先按"谁最像这张卡"排序，排在后面的直接砍掉，而不是靠一件软装去调和。

**第 3 步 · 材质不超过 3 种**
地面 / 墙面 / 柜体各算一种主材，点缀材质另加 1 种，合计 ≤ 3 + 1 [J-COL-02]。
木材只允许一种色系（同一色系不同深浅算一种）；金属只允许一种色（黑 / 银 / 铜选一）。
超了就删——先删"最贵的那一种"，它通常是后来加的。

**第 4 步 · 配色 60-30-10**
主色 60%（墙 + 大件家具）、辅色 30%（窗帘、地毯、柜门）、点缀 10%（抱枕、挂画、单椅）[J-COL-01]。
- 大面冷暖一致，不要一半暖白一半冷灰 [J-COL-03]；
- 点缀色与主色同色系或补色，高饱和色不超过 2 种 [J-COL-03]；
- 60-30-10 落地到**具体对象**：主色 = 墙面 + 沙发 + 地毯；辅色 = 窗帘 + 柜体；点缀 = 挂画 + 抱枕 + 绿植。

**第 5 步 · 一个空间只留一个焦点**
造型墙 / 异形沙发 / 大吊灯三者只能选一 [J-STY-03]。已经有电视墙的，沙发就选最普通的款；
已经有造型吊灯的，墙面就留白。想加第二个焦点时，先问"它解决什么问题"，答不出就删。

**第 6 步 · 硬装优先的冲突处理（这是本技能的核心判断）**
用户想要的风格与硬装冲突时，按这个顺序让：
1. 先让**风格**（换软装：布艺、地毯、灯具、挂画、五金件）；
2. 再让**家具造型**（换款式不换尺寸）；
3. 最后才动硬装，而动硬装不属于本技能 [J-STY-02]。
禁忌：为了做一面背景墙，把高柜塞到窗下或窗帘区——这违反 [J-CUR-01] 与 [J-WIN-01]，必须换位置，不能"为了风格牺牲可用"。

**第 7 步 · 落地与提交**
1. 用 `candidate.propose` 分批：先换材质（`material` 类修改），再换软装对象，最后加点缀；
2. 每次提交带 `base_version`；只改风格相关的对象，户型与位置不动 [J-VER-01]；
3. `candidate.review` 核对"只改了该改的"；`candidate.preflight` 确认没有把通行挤掉 [J-CIR-01]；
4. 主家具长度仍不超过所在墙面的 2/3 [J-PROP-01]；
5. 最多 3 轮修复 [J-VER-02]；3 轮后仍冲突的写进"未解决清单"（哪一件、为什么、可接受替代）。

## 依赖什么

本技能只使用以下语义能力（不含任何写场景权限）：

| capability | 用途 |
|---|---|
| `scene.read` | 读取现状 |
| `candidate.review` | 只给出约束与验收项，不改动候选 |

**边界**：不持有写权限（无 `scene.write` / `project.commit`）。技能只产出候选与验收意见，正式场景由主系统审批、落库与回滚。
**降级路径**：上述 capability 未接入时，输出坐标方案（mm，`at` 为家具中心）+ 验收清单，交主系统转成场景；不得声称已执行。

## 怎么验证

- **正向** `STY-dev-01`：4.0 × 5.2m 起居室，浅橡木地板 + 白门（硬装不可改），走北欧：主材橡木 / 棉麻 / 羊毛三种，60-30-10 为暖白—浅木—灰绿，焦点只有一个电视柜。期望 `candidate.preflight` 全通过。
- **边界** `STY-dev-02`：为了做"整面收纳背景墙"，把 2400 高的柜子放到北窗下。期望报 `CUR-01` 与 `WIN-01`；技能应拒绝该位置并给出"移到侧墙 / 降到窗台以下 / 改薄柜进深"三个替代。
- **反向校验**：把 `STY-dev-01` 的材质改成 4 种（加一种深胡桃），`candidate.preflight` 不会报错——说明材质数量只能靠人评，**不能假装自动**。

两个案例在 `examples/` 下，`ops.json` 可被 `tools/dry_run.py` 复跑；L1 结构与 L2 几何结果记录在 `manifest.validation`。
