# STY-dev-01 · 19㎡ 起居室的北欧（正向）

## 输入

- 场景：矩形起居室，轴线 4000 × 5200 mm，墙厚 200，内净 19.0㎡。
- 硬装（不可改）：浅橡木地板、白色平板门、暖白墙漆。
- 洞口：北墙窗 2200 宽（距西墙 900），窗台 900；东墙单开门 900（距北端 3800）。
- 用户原话："喜欢北欧，但别做成样板间那种冷白；预算有限，只换家具和软装。"

## 技能给出的风格卡

- 硬装基调：浅橡木 + 暖白 → 只能走北欧 / 日式原木 / 奶油，选北欧；
- 主材 3 种：橡木（茶几、边几、电视柜）、棉麻（沙发、窗帘）、羊毛（地毯）；
- 五金与线条：细黑金属、圆角、无把手；
- 软装关键词：浅色、留白、绿植、单枝。
- 配色：暖白 60%（墙面 + 沙发包布）／浅橡木 30%（地板 + 电视柜 + 茶几 + 边几）／灰绿 10%（绿植 + 抱枕 + 挂画）。
- 焦点 1 个：南墙电视柜这一段，其余三面墙留白、不加造型。

## 判定

`check.run` 应无 error；配色比例、材质数量、焦点数量属于人评项，按 `expected.md` 的清单核对。
