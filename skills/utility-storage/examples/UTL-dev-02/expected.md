# 预期结果

- `check.run`：**pass = false**。
- 必须出现：`DOOR-02` —— 南门 `d1` 的门扇扫掠矩形（x 900–1700 / y 1700–2500）与
  高柜 `o_cab`（x 1300–1700 / y 1500–2300）相交。
- 不应出现：`CIR-02`、`OVER-01`、`WALL-01`、`CUR-01`、`WIN-01`。
  （门口 300 深的落脚格还在；柜子与洗烘、拖把池、基站都不重叠；洞洞板仍贴西墙不压洞口；无窗。）

# 说明

这个案例是 2–6㎡ 小间最典型的"顺手"错误：门后看起来是空地，实际是门扇要走的弧。
它同时证明 `DOOR-02` 与 `CIR-02` 是两个口径：
- `DOOR-02` 管"门能不能开到底"；
- `CIR-02` 管"门口有没有落脚点"。
柜子堵住门弧但没堵死门口时，只会报前者——这正是本案例要固定下来的行为。

# 失效即表示

- 不报 `DOOR-02`：门扇矩形深度取错（应等于洞宽 800）或朝向取反（应往室内）；
- 若同时报 `CIR-02`：门口带与门扇矩形混成一条，会与"门后窄条可站人"的真实情况冲突；
- 若报 `OVER-01`：柜子与洗烘的容差判定（20）过严——它们并不重叠。
